공개자료 확인일: 2026-09-21. 데이터: `lib/forms/post-death-lookup-services.ts`.

## 기록과 신청을 구분하는 원칙

- 공식기관 제출서류는 각 기관에 제출한다. 이 사이트의 노트에는 관계·기관·재산/채무 종류·대략 금액·주식 수량·기준일·남은 질문을 적는다. 계좌번호·주민등록번호·증권번호·상세 주소·접수번호·인증정보는 복사하지 않는다.
- 고인의 로그인·인증수단으로 개인조회를 대신하지 않는다. 상속인 또는 별도 수급권자의 자격을 확인하는 절차를 사용하며 대리 신청에는 기관이 인정하는 권한·위임 자료가 필요하다.
- 금융조회·보험조회·휴면조회에 같은 자산이 나타나면 한 번만 기록한다. 보증·한도·근저당 채권최고액을 실제 대출잔액과 기계적으로 합산하지 않는다.
- 미회신·인증 실패·조회되지 않음은 없음·0원이 아니다. 신청 상태와 미확인 항목을 남기고 후속 확인으로 연결한다.
- 조회 신청·결과 확인은 지급·인출·처분·명의이전과 다르다. 실제 지급이나 처분 전에는 본인의 권한과 상속 선택에 미칠 영향을 별도로 확인한다.
- 조회 기한·결과 통지기간을 상속 승인·포기·세금 신고기한과 동일시하지 않는다. 새 법정기한 숫자나 계산기는 추가하지 않았다.

## 데이터 연결

`LookupService`를 확장해 `stepId`와 `application`의 자격·준비자료·대리·접수경로를 추가했다. 신청 자격의 법률상 판정을 저장하는 스키마가 아니다. `LookupTarget.label`은 기존 PLAN-01의 `family_context`·`asset_notes`·`debt_notes`·`unconfirmed_items`, PLAN-04의 `income_notes` 질문 문구와 동일하다. 관련 원본은 P0-01·P0-02·P0-03·P0-06·P0-16·P6-02·P6-03·P6-04·P6-05·P9-10을 연결한다.
