- 기존 자료실 113개와 신규 은행 회귀 19개를 구분해 유지한다. 원래 191개 기준 검사는 이전 편집층에 계속 적용하며 신규 편집층에는 197개를 별도로 검증한다.

- Windows sandbox에서 계산기 하위 프로세스가 EPERM으로 한 번 실패했으나 동일 시험을 정상 프로세스 권한으로 재실행해 통과했다.

- 최종 배포 SHA·Preview·1440/390px 화면 증거 및 A01~A20 결과는 배포 후 PR 검수 댓글에 기록한다. 빌드 성공만으로 실제 배포 검수를 완료로 간주하지 않는다.
