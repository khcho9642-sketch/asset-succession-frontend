# 채팅 기반 예상 세액 비교

2026-09-08 구현. 기존 PR #10의 채팅·확인·보고서 흐름에 실제 계산을 연결한다.

## 고객 흐름

`/precheck`에서 대화 → 정리 내용 확인 → 기본으로 켜진 **예상 세액 비교 포함** → 계산 분야·금액·적용 조건 확인 → 즉시 예상 세액 비교 → 최종 확인 → 7페이지 계산 보고서·PDF.

AI API 키가 없어도 기존 입력 정리 모드에서 계산과 보고서가 작동한다. AI는 금액을 추측하지 않으며 세액은 결정론적 코드가 계산한다. 실제 AI 연결과 PC의 Codex CLI 실행 검증은 별도이며, 이번 계산 테스트에서 호출하지 않는다.

정보가 부족하거나 적용 조건에 해당하지 않으면 계산된 0원 대신 확인할 항목을 표시한다. 고객이 비교 포함을 직접 해제하면 기존 사실·검토 후보 보고서를 이용할 수 있다.

## 이번 구현의 계산 범위

| 분야 | 실제 비교 | 주요 조건 |
| --- | --- | --- |
| 상속 | 배우자 최소공제 기준안, 법정지분 배분안, 선택한 배우자 배분액 | 거주자 1인의 재산, 배우자와 성년 자녀인 법정상속인, 사전증여·간주상속·추가 인적공제 없음. 일괄/기초·자녀·배우자·금융재산 공제 및 장례비·공과금·채무 반영 |
| 증여 | 같은 현금 총액을 한 명에게 증여 또는 실제 수증자들에게 균등 배분 | 같은 관계 유형, 10년 합산 증여·공제 사용 없음, 수증자 부담 세금, 세대생략 제외 |
| 양도 | 일반 비주거용 건물 현재 양도와 만 1년 추가 보유 | 같은 가격·비용·현행법, 만 2년 이상, 일반 장기보유공제·기본공제·국세·지방소득세. 주택·토지·중과·이월과세 등 제외 |
| 가업승계 | 같은 가업주식 일반 증여와 가업승계 증여세 과세특례 | 모든 특례 요건을 확인한 부모→성년 자녀 1명, 전체 주식이 적격이고 경영기간별 가액 한도 이내. 가업상속공제나 한도 초과 혼합 계산은 별도 |

36개 전략 모두의 세금을 계산했다는 표현을 사용하지 않는다. 서로 다른 재산 총액·종류·이전 사건의 세금을 바로 차감하지 않는다. 상속 비교는 1차 상속세이며 배우자의 향후 상속까지 합친 생애 세금이 아니다. 가업 증여 차액도 추후 상속 정산·추징을 포함한 생애 절세액이 아니다.

## 계산과 확인 경계

- 원 단위 정수로 계산한다. 억원 입력은 문자열에서 정확히 변환하고, 세액 표시는 원 단위다. 미입력·범위·추정·음수·과도한 금액은 계산하지 않는다.
- 일반 상속·증여는 적용 가능한 과세최저한 및 기한 내 신고공제를 반영한다. 가업 증여 특례에 신고공제를 적용하지 않는다. 국세와 지방소득세의 끝수 처리는 별도로 한다.
- 금융재산 전액을 납부 가능한 현금으로 간주하지 않는다. 납부 현금을 직접 입력한 경우에만 현금 부족액을 계산한다.
- 대화에서 파악한 자산을 계산 입력으로 옮기더라도 전체 평가액·지분·공제 요건은 고객이 확인한다. 장례비 500만원은 화면에 표시한 최초 모델 가정이다. 거주자·특례 요건·사전증여 부재는 자동 확인하지 않는다.
- 계산 입력을 수정하면 최종 확인이 해제된다. 원 대화의 사실이 바뀌면 이전 계산 조건과 보고서를 무효화한다. 같은 사실로 재방문하면 입력은 복구하지만 최종 확인은 다시 받는다.
- `taxComparisonInput`에는 분야, 조건, 확인 시각을 저장한다. 보고서를 열 때 같은 계산 모듈로 다시 계산한다. 결과 숫자를 별도 저장하거나 클라이언트가 보낸 계산 결과를 신뢰하지 않는다.
- 새로운 계산 보고서는 기존 미계산 후보와 섞지 않고 7페이지 전체에서 같은 계산 결과를 사용한다. 계산되지 않은 실행 비용을 세액과 합쳐 순이익으로 표시하지 않는다.

## 근거와 해석 검토

- [상증법 제19~22조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024572131)
- [증여 공제 제53조](https://www.law.go.kr/lsLinkProc.do?chrClsCd=010202&joNo=005300000%5E005400000&lsId=001561&mode=2), [과세최저한 제55조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024572777)
- [조특법 제30조의6, 2026-07-01 시행](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033268799)
- [국세청 양도 세율](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7711&mi=2312), [장기보유공제](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7710&mi=2311)
- 배우자 최소공제와 법정 공동상속인의 전액 협의분할은 조문 문구만으로 잘못 제한하지 않도록 [재산상속46014-508](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000069061) 및 [일괄공제 국세청 해석](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000071432)을 확인했다.

가업 특례의 과세표준 50만원 미만 부과 제외는 제30조의6이 제55조 제2항을 배제하지 않는 현행 조문 구조에 근거한다. 해당 숫자 경계만을 다룬 별도 예규는 확인하지 못했다. 특례 안내 중 오래된 요약 수치를 사용하지 않고 현행 법령을 우선했다.
