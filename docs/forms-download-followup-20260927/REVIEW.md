## 결과와 집계 단위

- 이전 대화의 32개가 아니라 실제 최종 카탈로그에서 파일 없는 공개 서식은 33개였다.

- 상속재산목록은 한정승인 청구서 합본 3쪽이다. 별도 문서로 재작성하지 않았으며 두 카드가 같은 원본을 연결한다.
- 사이트 내 원본 보관 6개 자료 / 파일 12개 / 실제 원본 기반 미리보기 6개.
- 제공기관 직접 다운로드 16개 자료 / 중복 제외 파일 18개.
- 이 중 공단 문서뷰어 직접 연결 12개 자료. 공무원연금 1개 자료는 기관 게시물에서 PDF 미리보기를 선택한다.

- 11개는 일치하는 원본을 확정하지 못했다. 각 항목의 상세 화면에 이유·문서명·제공처 경로를 남겼다.
- 공개 자료 198개, 서식 151개 / 조회·발급 25개 / 안내 22개는 그대로다.
- 전체 고유 파일은 사이트 보관 170 → 182개, 외부 직접 파일 4 → 22개다. 기존 ZIP·원본 파일은 변경하지 않았다.

## 원본·이용조건

- 다운로드 응답의 PDF/HWP 매직바이트, 크기, SHA-256과 실제 PDF 텍스트 또는 HWP PrvText 제목을 확인했다.
- 로컬 보관 파일 12개는 내려받은 원본과 바이트·크기·SHA-256가 같다. 이 검사는 개별 법적 적용 적합성 검토와 별개다.
- 대한법률구조공단의 공공누리 제2유형 자료는 원본이나 렌더 이미지를 이 상업 사이트에 재게시하지 않는다. 기관의 실제 다운로드와 공식 뷰어만 연결한다.
- 법원 공개 서식은 [전자가족관계등록시스템 저작권 정책](https://efamily.scourt.go.kr/sm/SmBottomCopyProtecPolic.do), 생활법령 공개 서식은 [법제처 저작권 정책](https://easylaw.go.kr/CSP/AboutCopyright.laf?topMenu=introUl3)을 확인하고 출처·원문을 유지했다. 별도 개별 이용허락을 받은 것으로 표시하지 않는다.
- 법령 별지는 국가법령정보센터 원본에 출처를 표시했다. 군인연금법 시행규칙 2024-05-01 시행본, 민간임대주택법 시행규칙 2025-12-19 시행본이다.
- HWP 내장 미리보기 4개는 저해상도임을 표시한다. 가짜 문서 이미지를 만들거나 내용을 다시 쓰지 않았다.
- 민간 계약서를 정부 공식 원본으로 표기하지 않는다. 외부 파일 버튼도 해당 제공처의 성격을 표시한다.
- 실제 배포 화면에서 확인한 오래된 "파일 열림 확인 전" 이용 안내를 신규 원본 확인 기록으로 갱신했다. 확인된 기관 원본은 제공 주체를 공공기관으로 보완하며, 민간 계약서의 민간 구분과 목적·시점·자산·자료유형은 보존한다.
