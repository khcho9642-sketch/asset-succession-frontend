## 원인과 변경

### A. 과거 혼인·출산 공제 보존

합산하는 과거 증여의 유효한 특별공제와 모든 증여자의 평생 사용액을 분리했다. 과거 공제는 합산 과세표준에서 보존하고, 다른 증여자의 공제는 이번 잔여 한도를 줄이는 데만 쓴다. 과거 과세표준에 해당 특별공제를 반영한 후 납부세액공제 한도를 계산한다. 이번 신규 특별공제는 별도 결과 행이다.

현재 지원은 동일한 아버지의 성년 자녀에 대한 유효한 일반 현금증여 이력이다. 과거 증여일, 혼인/출산 기준일, 당시 일반·특별공제, 신고 과세표준, 신고 산출세액, 일반 현금 이력 및 유효성을 확인한다. 과거 특별공제가 있는데 이력·금액·유효성이 미확인이면 정상 계산하지 않는다. 과거 특별공제와 이번 신규 특별공제 결합, 다른 증여자/중복 신고/특례/부담부/평가수수료/공제 취소 등은 이번 신규 지원에서 제외한다.

### B. 보험금 금융재산공제

보험금·사망 후 퇴직급여·금전신탁·기타 재산의 상속재산 포함액과 금융공제 대상액을 분리했다. 재산 총액에는 포함액만 한 번 더하고, 금융공제 분류에는 확인된 대상액만 사용한다. 금융채무는 총채무의 부분집합이며 과세가액에서 총채무로 한 번 차감한다. 합산 사전증여 현금은 현존 금융재산에 가산하지 않는다.

보험료 부담비율이나 수령 총액의 세법상 포함분을 새로 추정하지 않는다. 사용자가 이미 확인한 포함액을 입력한다. 사망 후 지급 퇴직급여 중 확인된 제외 유형은 금융공제 대상 0원이다. 사망 전 보유하던 예금까지 퇴직금 출처라는 이유로 제외하지 않는다. 미분해 양수 `deemedAssetsWon`, 미확인 분류, 포함액보다 큰 공제 대상액, 비과세 금융재산과 중복되는 복합 입력을 함수에서도 차단한다.

## 시험 연결

- 기존 계산기 93건 + 신규 47건(정상 숫자 16건, 차단·경계 31건) = 140건. 기존 기대 세액을 삭제하거나 낮추지 않았다.
- 기존 fixture에는 과거 특별공제 없음, 비과세 자산과 금융공제 중복 없음이라는 새 확인 사실만 명시했다. 기존 UI 시험에서도 과거 특별공제 없음을 선택한다. 기존 숫자 검증은 그대로다.
- 기존 별도 tax 105건, chat 모의시험 112건, phase2b 28건, 자료실 19건: 모두 유지한다. 총 단위시험은 404건이다. chat은 모의시험이지 외부 AI/MCP 실호출 검증이 아니다.
- B01~B20, B23~B24: `scripts/simple-calculator-final-tests.ts`에 ID별 직접 함수 시험. B23은 세목별 시작 전일/시작일/종료일/종료 다음날. 보험금 금융공제의 0/2천만/2천만+1/1억/1억+1/10억/10억+1 경계를 추가했다.
- B21~B22: `scripts/simple-calculator-final-ui.py`의 G01/I01 실제 입력, 수정, 모름/미지원, 없음/있음 복원, 재계산, 초기화. 기존 `simple-calculator-ui-audit.py`의 쉼표/커서/예시/세목 분리/모바일/초점 시험을 유지했다.
- 신규 라디오 시험은 키보드 Space를 사용하고 체크 상태를 검증한다. 기존 라벨 마우스 클릭 시험은 별도로 유지한다. 화면의 smooth-scroll 중 클릭 위치가 이동했던 시험 조작 문제를 피하되 합격 기준을 완화하지 않았다.
- 결과 이동 검사는 임의의 350ms 대기 대신 최대 10초 안에 결과 제목 전체가 viewport 안에 도착하는지 확인한다. 제목 초점과 실제 세액 검증은 그대로 유지한다.
- 320px에서 발견한 상단 메뉴의 7px 넘침은 계산기 페이지에 한정된 CSS 여백 조정으로 해결한다. 공통 메뉴 구현과 다른 페이지는 바꾸지 않으며 44px 버튼 크기를 유지한다. B20의 국세 환급·지방세 납부가 서로 다른 방향인 화면도 실제 브라우저에서 검사한다.

## 근거와 직접 대조 한계

공식 본문은 2026-09-20에 재확인했다. 첨부 법령 `lsiSeq=276123`은 **2025-10-01 시행 판본**으로 표시된다. 확인일을 시행일로 잘못 표시하던 라벨은 바꿨다. 지원일 상한을 자동 확장하지 않았다.

[제55조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0055&lsiSeq=276123&urlMode=lsScJoRltInfoR)의 과세표준 공제, [제58조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0058&lsiSeq=276123&urlMode=lsScJoRltInfoR)의 종전 산출세액 및 과세표준 비율 한도와 함께 검토했다. 이 조합에 따른 독립 산식이지 홈택스 출력은 아니다.
- [국세청 증여세 항목별 설명](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7960&mi=6533): 10년 동일인 합산, 관계별 공제, 산출세액, 신고공제 및 납부세액공제 본문 확인. 잘못된 메뉴 조합을 수정했다.
- [보험금 재산세과-843 (2009-11-24)](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000137520): 금융기관 보험금 중 상속재산 포함 부분의 금융공제 근거. [국세청 공제표](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7956&mi=6528), [법 제22조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0022&lsiSeq=276123&urlMode=lsScJoRltInfoR)와 구간·한도를 대조했다.
- [퇴직연금 상속증여세과-615 (2013-12-10)](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000152375): 상속개시 후 지급 퇴직연금 제외 사실관계 확인. 해당 공식 본문에 인용된 사전증여 금융재산 제외도 검토했다. 모든 퇴직 관련 상품의 일률 제외로 일반화하지 않는다.
- [양도 흐름도](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7709&mi=2310)와 [공개 고가주택 사례](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8799&mi=12271): 경로 및 제목/본문 확인. 공개 사례 2건은 기존 회귀시험을 유지했다. 이번 C01~C05와 동일한 홈택스 직접 실행으로 표시하지 않는다.

**공식 직접 비교:** 이번 G01/I01/I06/C02의 동일 전체 입력에 대한 홈택스 직접 대조는 미실행이다. 2026-09-19 실제 접근 기록에서 증여/상속 자동계산은 로그인 필요 메시지를 반환했고, 공개 간편계산에는 과거 특별공제/보험금 금융분류/수증자별 신고 내역 등 같은 조건을 모두 입력할 수 없었다. 양도 비로그인 화면은 개별 국세 계산을 확인했으나 두 거래의 연간 합산·기납부/지방세 차액 결과를 확보하지 못했다. 이 제한을 해소했다고 주장하지 않는다. 해당 기록은 이전 검증과 구분하며, 정당한 공제를 지워 간편계산 결과에 맞추지 않았다.
