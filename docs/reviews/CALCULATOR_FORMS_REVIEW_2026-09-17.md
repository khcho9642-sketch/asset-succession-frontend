## 공식 근거와 적용 범위

- [상속세 및 증여세법 제22조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032161999): 금융재산에서 금융채무를 뺀 순액으로 공제를 산정. 2026-01-02 시행본 확인.
- [상증법 제53·55·58조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026647923): 관계별 10년 공제 한도, 합산 재산의 공제와 종전 산출세액공제 한도. 같은 시행본 확인.
- [국세청 납부세액공제 한도 해석](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=200000000000001535): 종전 공제가 없었던 경우의 공제액 안분을 회귀시험으로 구분.
- [국세청 2017년 거주요건 경과규정 해석](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000515008): 2017-08-03 이후 조정대상지역 취득의 거주요건. 경과규정·상속 취득 등 특례는 간편 지원 범위 밖이다.
- [국세청 고가주택 산식·공개 예제](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8799&mi=12271): 2021-12-08 이후 12억원 기준. 양도차익과 전체 장기보유공제를 각각 안분한다.
- [국세청 2022년 안내 책자](https://www.nts.go.kr/upload/nts/ebook/sw_1227_j/sw_1227_j/assets/contents/download.pdf): 공개 고가주택 예제와 2021-06-01 이후 주택 단기세율 확인.

상속·증여는 2023-01-01~2026-09-17, 양도는 2021-12-08~2026-09-17의 지원 기간을 명시한다. 양도 기본세율은 2021~2022년과 2023년 이후를 구분한다. 확인일 이후 날짜는 계산하지 않는다.

## 검증 종류 구분

1. 국세청 직접 계산 결과 대조: **공식 대조 미실행**. 손택스 간편계산 주소는 HTTP 200이었으나 현재 홈 화면을 반환했다. 계산 결과를 확보하지 못했다.
2. 공개 예제 대조: 국세청 2022-01-03 고가주택 사례의 과세차익 134,000,000원, 장기보유공제 107,200,000원과 일치. 책자 2022-01-15 사례의 과세표준 35,500,000원, 국세 4,245,000원과 일치.
3. 산식 검토: 위 법령·국세청 자료에 따라 첨부 반례 기대값을 채택. 공개 예제에 없는 지방세·최종 합계까지 공식 산출 결과라고 주장하지 않는다.
4. 내부 단위시험: 계산기 기존 5개 + 신규 41개 = 46개. 기존 세액·경계값을 삭제하지 않았다.
5. 기존 회귀시험: tax 105개 + chat 112개 + phase2b 28개 = 245개. 실서비스 AI/MCP 호출 없음.
6. lint, typecheck, production build 통과. 최종 커밋은 CI와 Preview에서도 같은 시험을 재실행한다.

- 일반 지원범위 안내는 scopeNotes로 분리하여 정상 계산에 차단 경고가 붙지 않는다.

- 빈 초기값, 예시 분리, 명시적 0/모름, 세목별 상태, 수정 시 이전 결과 무효화, 초기화를 유지했다.
- 브라우저 CI run 35113554193: 금액 변경 후 지연된 requestAnimationFrame 커서 복원이 다음 입력의 커서를 덮어쓰던 경합을 확인했다. useLayoutEffect에서 해당 렌더의 선택 영역을 복원하도록 수정했다.
- 기존 중간 삽입 기대값 19,234,567원을 유지하고 커서 위치·삭제 검사도 추가했다. 실제 라벨과 도움말이 섞이지 않도록 접근성 이름을 분리했다.
- 모바일 세목 탭은 한 줄에 모두 들어오도록 최소 너비만 보완했다. 디자인 재구성 없음.
- 실제 전송되지 않던 상담 연락처 폼은 제거했다. 카카오·전화·이메일 직접 문의와 기존 진단 결과 링크는 유지한다.

## 자료실 원본 교체

- 후보 74개는 확보 완료 목록이 아니다. 이번 공개 목록은 10개 항목이며 2개 항목만 파일을 재호스팅한다. 나머지 8개는 공식 제공처 연결이다.
- 부평구청 상속재산분할협의서(2020-01-03), 증여계약서(2026-03-27): 원본 HWP 2개와 기관 작성 예시 HWP 2개를 실제 첨부 주소에서 다운로드했다.
- 두 게시물의 공공누리 제1유형(출처표시)을 확인하고 웹페이지·매니페스트에 출처를 표시했다. 문서 내부를 수정하거나 로고를 추가하지 않았다.
- 4개 모두 HWP v5 구조·압축 본문·제목·내장 미리보기를 확인했다. 원본 문서의 전체 인쇄 레이아웃과 한컴/Word 호환 열림은 미검증이다.
- 웹 미리보기 2개는 기관 HWP에 내장된 이미지다. 상속 예시 이미지는 저해상도이며 문서 내용을 재작성하거나 선명한 원본처럼 표시하지 않는다.
- 서울중앙지법 3개 항목은 목록의 양식·작성방법·예시 제공 안내를 확인했다. 재배포 조건과 개별 파일 열림 미확인으로 기관 링크만 제공한다.
- 국세청 5개 항목은 공식 목록의 제목·제공 경로를 확인했다. 개별 원본과 기관 작성 예시는 확보했다고 표시하지 않는다.
- 기존 자체 DOCX/XLSX/PDF, 가상 예시, 합본·이용안내, ZIP, 매니페스트, 썸네일 등 공개 파일 38개를 제거했다. Git 이력은 보존한다.
- 기존 index.html은 /forms로 연결한다. 나머지 37개 URL은 새 Preview에서 404/410인지 검사한다.
- 원본 비교는 이전 자체 파일과의 일치가 아니라 **기관에서 내려받은 4개 바이너리의 SHA-256 일치**다. 매니페스트에 원본/예시 각각의 해시를 기록했다.
- 새 ZIP은 확인한 HWP 4개만 포함한다. 재배포 조건이 미확인인 자료를 묶지 않는다.
- 이전 Production 및 과거 불변 Preview 배포물은 이번 작업에서 변경·삭제하지 않는다. 공개 철회는 이번 수정 커밋의 Preview에 적용된다.
