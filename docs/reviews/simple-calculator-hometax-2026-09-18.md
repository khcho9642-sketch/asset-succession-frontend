## 확인된 별도 오류와 수정

금융재산 입력 전부를 공제 대상으로 간주하는 문제가 있었다. 공제 제외 재산을 입력할 수 없어 해당 재산까지 자동 공제됐다. 같은 재산 15억원 사례에서 금융재산 중 제외 재산이 5천만원이라면:

- 수정 전: 제외 조건을 표현하지 못해 공제 4천만원, 세액 58,588,000원.
- 수정 후: 공제 대상 순금융재산 1억5천만원, 공제 3천만원, 세액 60,528,000원.
- 총 상속재산 15억원과 과세가액 13억9,200만원은 그대로다. 공제 제외 금액을 비과세로 빼지 않는다.
- 금융채무는 공제 대상 순금융재산 계산에 반영하되, 과세가액에서는 기존 총채무로 한 번만 차감한다.

입력에 금융재산 중 공제 제외 재산의 없음·있음·모름을 추가했다. 있음일 때 금액 하나만 받는다. 빈 선택·모름·미입력·음수·소수·금융재산 초과는 계산 완료로 처리하지 않는다. 금융재산이 명시적으로 0원인 경우에는 제외 금액도 0으로 처리한다. 조건을 없음으로 바꾸면 이전 세부금액을 계산에서 제외하며, 되돌리면 입력값은 보존한다.
