### 다운로드가 되지만 잘못된 문서였던 항목

NTS-CG-15의 기존 목록 링크 `https://www.nts.go.kr/upload/ti_tax/01/개인지방소득세 납부서.hwp`는 실제 본문이 **별지 제39호의5서식: 토지등 매매차익에 대한 개인지방소득세 예정신고 및 납부계산서**였다.

실제 **별지 제40호서식: 개인지방소득세 납부서**를 [국세청 해당 게시물](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2240&nttSn=1002309)의 첨부로 교체했다. 원 후보의 `sourceUrl`은 추적을 위해 보존하고 파일의 `sourcePage`·`sourceCorrection`에 정정 출처를 따로 기록했다. 잘못된 파일은 공개 저장소에 등록하지 않았다.

## 이용 조건과 확인 한계

- 부평구청, 동대문구: 해당 게시물의 공공누리 제1유형 표시 확인. 동대문구는 게시물 하단 `kogl_mark1`, `img_opentype01.png` 이미지에 표시되어 본문 텍스트 검색만으로는 발견되지 않았음.
- 법원 자체 양식: [법원 저작권정책](https://www.scourt.go.kr/portal/popup/jeojak_pop.html)의 기관 보유 자료 이용 정책을 근거로 출처·정책 링크를 표시. 원본을 수정하지 않음.
- 법령 별지 서식: [저작권법 제7조 제1호](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029423769)(확인한 조문 시행 2026-08-11)에 따라 법령의 일부인 서식으로 분류. 이를 국세청이 자체 집필한 작성사례에도 일괄 적용하지 않음.
- 등기 양식: [생활법령정보 저작권정책](https://easylaw.go.kr/CSP/AboutCopyright.laf?topMenu=introUl3)에 따른 출처 표시. 제공 기관의 법원 등기 양식 원본만 이용.
- 국세청 자체 작성사례 4항목: [국세청 저작권정책](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=6791&cntntsId=8169) 확인. 개별 자료의 자유이용 표시 미확인이라 로컬 재배포와 묶음에서 제외. 이 중 HWP 첨부가 있는 3항목만 기관 서버의 파일을 직접 받을 수 있음.
- 원본 해시 일치는 문서의 진본 바이트 보존 검사이지, 최신 법령 적용·기관의 접수 승인·전문가 검토 완료를 뜻하지 않음.
- 게시 당시 문서이며 2007/2010/2011/2016/2020/2021년 등 예전 양식도 있음. 최신 접수 요건 확인 안내 유지.
- HWP/Word의 네이티브 프로그램 전체 인쇄 레이아웃은 미검증. PDF 렌더링 검사와 구분. 두 `.doc`는 기관이 그 확장자로 제공한 RTF 파일임.

## 회귀 검사

- 기존 자료실 시험 8개 유지·제공 상태 기대값 변경, 신규 6개 추가: 전체 139파일 해시/크기/형식, 법원 3형식 연결, 한글·괄호 경로 인코딩, 잘못된 납부서 교체, 묶음 제외 범위, 재배포 근거 구분.
- Next.js 정적 파일 경로는 각 세그먼트의 `encodeURIComponent` 표기와 일치해야 함. 괄호를 `%28/%29`로 과잉 인코딩하면 파일이 있어도 404가 나던 문제를 재현하고 수정.
- 기존 계산기 46, 세액 105, 채팅 모의 단위시험 112, Phase2B 28 유지. 자료실 14와 합계 **305개**. 실제 Google AI·MCP 호출 없음.
- lint, typecheck, build 유지. 브라우저 검사를 없애거나 가로 넘침 기준을 완화하지 않음.
- 브라우저: 320/360/390/768/1024/1280/1440px, 74개 카드·분야 검색, 73개 다운로드와 1개 미확보 표시, 공식 등기 4카드·8링크, 모달 초점, Word/HWP/PDF 선택 다운로드, 한글 파일명, 139개 GET 및 일괄 묶음 해시 검증.
- 기관 외부 다운로드의 실시간 검사는 `FORMS_VERIFY_EXTERNAL_DOWNLOADS=1`로 실행. 로컬 및 Preview에서 3개 실제 브라우저 다운로드를 별도 검증하며 CI는 기관 가용성에 의존하지 않는 정적·로컬 검사를 실행.
- 기존 자체 제작 파일 37개 직접 URL의 404/410 및 옛 index의 `/forms` 이동 검사 유지.
- 검사는 `.tmp/forms-library-proof/verification.json`에 결과·스크린샷을 출력. 배포 커밋과 Preview 실측 결과는 같은 Draft PR의 최신 보고에 기록.

### 연속 다운로드 CI 점검

첫 CI `35196789292`는 305개 단위시험·lint·typecheck·build와 계산기 브라우저 검사를 통과한 뒤, 자료실의 연속 형식별 다운로드 이벤트에서 시간 초과했다. 같은 코드의 로컬 및 실제 Preview에서는 전체 파일·해시·브라우저 검사가 통과했다.
Chromium의 [LocalFrame::ShouldThrottleDownload](https://chromium.googlesource.com/chromium/src/+/6093f61a7bcb77bf706fcd022b8d0f1447b5f60e/third_party/blink/renderer/core/frame/local_frame.cc)에는 프레임당 연속 다운로드 제한과 1초 초기화 구간이 있다. CI가 여러 다운로드를 빠르게 연속 실행한 영향으로 추정하여 형식 선택 시험의 각 클릭 간격을 1.1초로 제한하고 파일별 진행 로그를 추가했다. 파일 수·해시·실제 다운로드 이벤트 단언을 유지했으며 브라우저 보안 설정을 해제하지 않았다. 최종 CI 결과는 PR에 기록한다.

묶음 재현: `python scripts/build-official-forms-bundle.py`. 이 스크립트는 매니페스트의 사이트 보관 파일만 해시 확인 후 결정론적으로 압축하며, 다운로드·재작성·외부 파일 수집을 하지 않음.
