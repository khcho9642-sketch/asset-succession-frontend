# 74개 자료 다운로드 완료 변경

기준: ac64b3e2c0b8473ce83924d0b3104fb860b7a040. 작업 브랜치 `codex/calculator-forms-review`.
대상 저장소 `khcho9642-sketch/asset-succession-frontend`, 기존 Draft PR #5.

## 변경 범위

- NTS-IE-01~03: 국세청 첨부 HWP 3개를 원본 그대로 사이트 경로에 등록.
- NTS-CE-01: 원본 PNG 5개 및 웹 본문·이미지를 묶은 PDF 1개 등록.
- PDF는 기관 제공 PDF가 아닌 사이트 변환본. 첫 쪽에 원문 사례 조건, 다음 다섯 쪽에 원본 이미지와 별도 출처 각주. 원본 이미지의 픽셀을 수정하지 않음.
- 원문 이미지 자체는 금액을 채운 신고서가 아닌 빈 서식·작성방법. 이를 AI로 채우거나 사례를 재계산하지 않음. 사례 거래일은 2020-02-15.
- 74개 레코드 모두 사이트 개별 다운로드 및 전체 묶음에 포함. 원본 147개 + 변환 PDF 1개 = 148개 파일. ZIP에는 README·manifest를 더해 150개 항목.
- 기존 70개 레코드, 계산기·메인·채팅·MCP·보고서·상담 페이지와 등기 카드 4개/링크 8개는 변경하지 않음. 원격 `assistant/forms-additions-61`의 별도 작업을 병합하거나 덮어쓰지 않음.

## 이용 근거의 구분

국세청이 국세신고안내의 세목별 작성사례로 공개한 업무상 저작물로 판단해 출처를 유지하여 게시한다.
[저작권법 제24조의2](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030281869)는 국가가 업무상 작성·공표한 저작물 등의 자유이용과 예외를 규정한다.
[국세청 정책](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=6791&cntntsId=8169)의 공공누리 표시 확인 및 미표시 자료 사전협의 안내도 출처 기록에 보존한다.

이번 판단을 개별 공공누리 제1유형 확인이나 국세청의 별도 허락 취득으로 기록하지 않는다. 사용자 요청은 게시 진행 결정이지 저작권자의 허락 증빙으로 취급하지 않는다. 개별 계약·저작권 등록 여부까지 확인한 법률 검토는 아니다. `rightsReview`에 이 범위와 제한을 기록한다.

## 무결성 및 검사

- HWP 3개와 PNG 5개는 이전에 실제 공식 서버에서 확보·검사한 원본 8개의 SHA-256과 크기를 고정해 시험한다.
- PDF는 6쪽 전체 렌더링 및 내장 이미지 5장의 디코딩 픽셀을 원본과 대조한다. 자체 PDF 해시는 기관 제공 PDF와의 일치를 뜻하지 않는다.
- 기존 자료실 14개 시험을 삭제하지 않고 제공 상태·묶음 수 변경에 따른 기대값을 갱신. 원본 8개 해시, 변환본 구분, 이용 근거 과장 방지 시험 3개 추가: 자료실 17개.
- 브라우저 검사는 기존 139개에서 148개 전체 파일 응답·해시 및 ZIP 150개 항목으로 확대. 신규 4개 카드와 이미지/PDF 형식 선택의 실제 다운로드 이벤트·파일명·해시·페이지 유지까지 확인.
- 다운로드 연속 실행은 기존 Chromium 버스트 제한 대응인 1.1초 간격을 유지. 검사 삭제·타임아웃만 연장하는 방식으로 통과시키지 않음.
- 환경변수 변경·운영 배포·병합 없음. 최종 검사 및 Preview 주소는 PR에 같은 커밋 기준으로 기록.
