## 구현

별도 `/forms` 페이지에 승인된 자료실을 구현했습니다. 메인화면을 교체하지 않습니다.

- 기존 `PublicNav` 재사용. 별도 복제 헤더 없음.
- 기존 서류양식 링크가 사용하는 `/downloads/asset-succession-forms-v1/index.html`만 `/forms`로 307 연결.
- 10종 작성 양식, 전체 및 5개 분야 필터, 문서명·용도 검색.
- 실제 가상 작성 예시 PDF의 첫 페이지 썸네일 및 모달 미리보기.
- 원본 Word/Excel, 전체 작성 예시 PDF, 이용안내, 전체 ZIP 링크.
- 모바일 카드형 구성과 모달 키보드 접근·초점 복원.
- 기존 문서의 자체 참고 초안·전문가 검토 전 안내 유지.

자료실 경로에만 적용되는 좁은 화면 보정에서 중복되는 현재 페이지 아이콘을 숨겼습니다. 공통 메뉴에서 서류양식 링크는 유지하며 다른 페이지의 헤더/CSS는 수정하지 않았습니다.
