# asset360 AI 가상상담 시험

이번 시험은 `codex/ai-conversation-trial`의 보호된 Vercel Preview에서만 진행한다. 운영 `main`과 `asset360.intellic.co.kr`의 고객용 AI 활성화는 별도 작업이다.

## 실행 조건

다음 조건을 모두 만족할 때만 `/api/diagnosis`가 모델을 호출한다.

- `VERCEL_ENV=preview`
- `VERCEL_GIT_COMMIT_REF=codex/ai-conversation-trial`
- `AI_DIAGNOSIS_FREE_TRIAL_ENABLED=true`
- `GOOGLE_DIAGNOSIS_MODEL=gemini-3.5-flash-lite`
- 서버 전용 `GOOGLE_GENERATIVE_AI_API_KEY`가 존재

세 가지 설정은 해당 Preview 브랜치에만 저장한다. 키는 기존 Google AI Studio **APCI** 프로젝트의 무료 등급 키를 사용하며 저장소·브라우저 번들·로그에 기록하지 않는다. 결제 연결이나 등급 변경은 하지 않는다. 무료 서비스에 실제 고객의 개인정보·민감정보·비밀정보를 입력하지 않는다. 시험 배너가 표시되는 화면에서 가상 정보만 사용한다. Vercel 배포 보호는 유지한다.

기본 모델은 `gemini-3.5-flash-lite`의 `minimal` 설정이다. 초기 `gemini-3.8-flash` 시험에서 복합 입력의 시간 초과와 5xx가 관측되어 짧은 상담 응답에 맞는 모델로 조정했다. 실패 시 다른 서비스로 전환하지 않는다. 동일 프로젝트의 `gemini-3.8-flash`는 일시적인 5xx·연결 실패·시간 초과에만 한 번 사용한다. 인증·할당량·결제·잘못된 입력·원문/형식/세액 검증 실패는 즉시 사용자에게 알린다. 두 모델 모두 해당 무료 등급 프로젝트의 표준 텍스트 API만 사용한다.

2026-11-16 기준 [Google 공식 가격표의 Flash-Lite 표준 입력·출력 무료 항목](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite)과 AI Studio의 APCI 무료 등급을 확인했다. Google 검색·지도 그라운딩, 캐시 생성, 유료 모델은 이 시험에서 호출하지 않는다.

## 답변과 기억

기존 `{messages,facts}` 요청과 `facts/message/choices/selectionMode/inputMode` 응답을 유지한다. 첫 인사와 화면 이동은 앱이 처리하고, AI 모드의 이후 자유 입력과 선택지 답변은 현재 대화에 따라 생성한다. 명시적으로 선택하는 직접 입력 모드는 별도로 표시한다.

고객의 고민에 먼저 답한 후 필요한 정보 하나만 묻는다. 선택지는 질문에 맞게 2~4개이며 자유 입력은 항상 가능하다. 종료·정리 요청은 추가 질문 없이 마친다. 증여·상속 비교를 임의로 한 주제로 축소하지 않는다.

상담을 정리하거나 결론을 요청하면 사실 목록에서 끝내지 않는다. 현재 정보로 가능한 판단과 이유, 구체적인 다음 행동, 아직 확정할 수 없는 점을 차례로 짧게 설명한다. 희망과 법적 가능성은 구분하고, 이미 발생한 상속의 처리와 생전 승계 계획을 혼동하지 않는다. 사실 요약만 명시적으로 요청하거나 단순 종료를 원하면 판단을 강요하지 않는다. 세액·법률상 가능성 확정과 계산·접수 실행은 기존의 검증·확인 절차를 따른다.

AI 모드에서는 계산 조건을 채우기 전에도 ‘간략 검토보고서’를 만들 수 있다. 현재의 완전한 AI 결론이 없으면 고객이 보고서 만들기를 선택했을 때 같은 대화로 정리 요청을 보낸다. 이 요청에는 새로운 고객 사실이 없으므로 facts와 choices는 빈 배열로 제한한다. 검증된 응답을 받은 뒤 앱이 보고서를 연다. 실패·중지·새 사실이나 정정 뒤의 이전 응답·직접 입력 모드의 고정 안내는 AI 검토보고서로 재사용하지 않는다.

간략 보고서는 AI 판단·우선할 일·확인할 사항, 고객 원문과 근거, 미확인 내용을 구분한 확인 전 초안이다. 인쇄/PDF 저장, 대화로 복귀, 세액 계산·상세 보고서 준비를 제공한다. 세액은 미산정으로 표시하며 기존의 고객 확인·계산 조건·상세 보고서 생성 조건을 우회하지 않는다. 대화 복원 뒤 같은 보고서를 볼 때 새 API 호출을 요구하지 않고, 고객이 사실을 추가·정정하면 새로운 AI 정리를 받아야 한다.

“이유만 설명해 주세요”처럼 설명만 명시적으로 요청하면 추가 선택지 없이 답한다. 순수한 설명 요청을 가족·재산의 사실 메모로 저장하지 않으며, 요청에 실제 추가 정보·정정·모름이 함께 있으면 해당 사실은 보존한다.

사실은 최신 고객 원문의 연속 인용과 메시지 ID로 검증한다. 내부 모델은 서버가 만든 원문 후보의 `sourceId`를 선택하고, 서버가 해당 번호를 원래 `value/evidence`로 복원한다. 모델이 금액·단위·어미를 다시 쓰지 않으므로 원문 의역 때문에 정상 상담 전체가 거절되는 경로를 줄인다. 외부 API와 저장 초안의 형식은 유지한다. 추가 사실과 원문 근거를 누적하고, 명확한 부분 정정은 해당 대상만 바꾼다. 수증자와 미확인 사항을 별도 기록한다. 모름을 없음·0원으로 취급하지 않는다. 모호한 정정이나 상충 정보는 임의로 확정하지 않는다. 기존 v1 저장 초안도 읽는다.

모델의 사실·답변 전체를 검증한 뒤 한 번에 반영한다. 근거 없는 세율·공제·세액·절세액 및 계산·접수·화면 이동 완료 주장은 거부한다. 검증 실패를 고정 상담 답변으로 대체하지 않는다. 입력을 복원하고 같은 사용자 메시지로 재시도하거나 직접 입력을 선택할 수 있게 한다.

이미 모른다고 답한 정확한 항목의 금액·유무 등을 다시 묻는 응답은 대화 품질 검사에서 걸러낸다. 첫 시도에서 이 문제가 감지되면 같은 모델에 해당 항목을 보류하라는 짧은 교정 지침을 주고 한 번 다시 생성한다. 고정 답변으로 바꾸지 않으며, 이 경우 보조 모델 호출을 추가하지 않는다. 공급자 장애의 보조 시도와 품질 교정은 연쇄하지 않고, 한 요청 전체에서 모델 시도는 최대 두 번이다. 두 번째도 검사를 통과하지 못하면 사실·답변을 반영하지 않고 재시도 안내를 제공한다.

“확인이 필요해요” 같은 짧은 선택지 답변은 직전의 명확한 단일 질문과 연결한다. 저장된 사실에 아직 반영되지 않아도 대화 이력의 미확인 대상만 정해진 항목 코드로 유지하며, 고객이 해당 대상을 명확히 확인·정정하면 해소한다. 이 과정에서 AI가 앞서 말한 금액이나 사실을 고객 사실로 가져오지 않는다.

시험 중 실패 원인은 활성화된 동일 Preview 브랜치에서만 범주로 기록한다. 스키마 오류 코드·허용된 필드 경로, 제안·수락한 필드 이름, 검증 종류, 종료 사유와 토큰 수, 공개 오류 코드만 허용한다. 고객 원문·사실 값·금액·프롬프트·모델 응답·API 키·원본 오류 객체는 로그에 남기지 않는다.

고객 확인, 기존 계산기, 보고서 생성과 상담 접수는 앱이 결정한다. AI 응답 자체는 법령 검증·세액 계산·접수 결과가 아니다.

## 검증 기준

로컬 단위 검증과 CI의 모델 모의 응답 검증에 이어, 보호된 Preview에서 **실제 API**로 가상 대화를 진행한다.

| 상황 | 확인할 내용 |
|---|---|
| 상속·증여 비교 | 건물 20억·예금 3억·자녀 둘 동시 입력, 대출 5억/보증금 모름, 대출만 3억 정정, 이유 설명, 종료 |
| 증여 | 수증자·재산 추가, 기존 정보 유지, 모름 보존 |
| 양도 | 자산·취득 정보·시기 추가, 주제에 맞는 질문 |
| 가업승계 | 가족에게 지분 이전, 미확인 가치, 주제 변경 |

각 대화의 답변·정리된 사실·고객 확인 화면이 일치해야 한다. 모바일 버튼·입력 복원·동일 메시지 재시도·직접 입력 전환은 CI에서 별도 확인한다. 자료대장 220개 ID와 원본 458개 파일의 변경·누락도 독립 기준과 대조한다. 실제 API 검증 전에는 설정 성공을 대화 성공으로 기록하지 않는다.

실제 시험에서 확인한 인계 보완도 포함한다. 명확하게 말한 배우자 유무는 계산 조건에 이어받고, 보증금 등 채무 미확인이 남아 있으면 알려진 대출만 채무 총액으로 채우지 않는다. 아파트·주택을 명시한 양도 상담은 해당 자산 유형을 선택하되, 취득가·매도가의 의미나 비과세·지원 요건을 임의로 확정하지 않는다. 금액을 모르는 재산도 재산 항목과 미확인 내용에 남긴다.

시험을 중지하려면 이 브랜치의 Preview 활성화 플래그를 `false`로 변경하고 다시 배포한다. 운영 설정과 도메인은 변경하지 않는다.

환경변수 변경은 새 배포부터 적용된다. 이전의 불변 Preview까지 중지해야 한다면 해당 배포의 접근 관리나 제거를 별도로 처리한다. 배포 보호를 해제하거나 운영 환경으로 시험 키를 복사하지 않는다.
