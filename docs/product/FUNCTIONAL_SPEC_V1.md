# 자산승계 360 기능정의 V1

## 제품 목적

자산승계 360은 공개 방문자가 회원가입 없이 가족·자산·채무·승계 목표를 입력하고, 내부 36개 시나리오 후보 중 개인에게 필요한 기준안·추천안·납세재원 보완안만 확인한 뒤 무료 사전진단 보고서와 조경호 회계사 상담으로 이어지는 UI 프로토타입이다.

## MVP 포함

- 공개 랜딩페이지
- 무가입 5단계 사전진단 wizard
- 브라우저 세션 내 `assessment_id` 생성과 사전진단 입력 스냅샷 인계
- 36개 내부 후보 분석 요약과 기준안 1개, AI 추천 최대 3개, 추가 검토안 최대 2개, 납세재원 보완안 1개
- 무료 보고서 미리보기 및 브라우저 PDF 저장 동작
- 로컬 검증·접수완료 상태를 갖는 상담 신청 화면
- 전문가 프로젝트 개요
- 전문가 시나리오 작업공간
- 공개/전문가 navigation 분리
- 합성 mock data 기반 화면

## MVP 제외

- AI API
- 실제 세법 계산 엔진
- FastAPI, Streamlit, SQLite, MCP 연결
- 인증, 결제, 운영 데이터베이스
- 실제 고객 개인정보 저장·전송

## 시나리오 노출 범위

36개 후보는 내부 로직과 테스트에서만 전체 평가한다. 사용자 화면과 PDF에는 36개 전체 목록, 전체 매트릭스, 제외된 시나리오 목록을 표시하지 않는다.

사용자에게 보여주는 범위:

1. 현 상태 기준안
2. AI 추천 시나리오 최대 3개
3. 필요한 경우 추가 검토안 최대 2개
4. 보험·연부연납 등 납세재원 보완안 1개

## 핵심 원칙

- 공개 사용자는 전문가 화면으로 이동하지 않는다.
- 결과·보고서·상담 화면은 같은 브라우저 세션의 사전진단 입력 스냅샷과 `assessment_id`를 표시한다.
- 상담 신청 제출은 네트워크 전송 없이 로컬 성공 상태만 표시한다.
- 모든 세액·비용은 합성 예시 또는 검토 상태이며 확정 세액으로 표현하지 않는다.
- 실제 개인정보, 비밀키, MCP 설정, 백엔드 연결은 포함하지 않는다.
