# 자산승계 360 기능정의 V1

## 제품 목적

자산승계 360은 공개 방문자가 회원가입 없이 가족·자산·채무·승계 목표를 입력하고, 상속·증여·매각·부담부증여·가족법인·보험·혼합 전략을 비교한 뒤 무료 사전진단 보고서와 조경호 회계사 상담으로 이어지는 UI 프로토타입이다.

## MVP 포함

- 공개 랜딩페이지
- 무가입 5단계 사전진단 wizard
- 브라우저 세션 내 `assessment_id` 생성과 사전진단 입력 스냅샷 인계
- 7개 승계 전략 비교 결과
- 무료 보고서 미리보기 및 브라우저 PDF 저장 동작
- 로컬 검증·접수완료 상태를 갖는 상담 신청 화면
- 전문가 프로젝트 개요
- 전문가 시나리오 작업공간
- 공개/전문가 navigation 분리
- 합성 mock data 기반 화면

## MVP 제외

- AI API
- 실제 세법 계산 엔진
- FastAPI, Streamlit, SQLite, MCP 연결
- 인증, 결제, 운영 데이터베이스
- 실제 고객 개인정보 저장·전송

## 전략 범위

1. 현 상태 유지 후 상속
2. 일부·단계적 증여
3. 매각 후 현금 증여
4. 부담부증여 검토
5. 가족법인 활용
6. 보험 납부재원
7. 혼합 전략

## 핵심 원칙

- 공개 사용자는 전문가 화면으로 이동하지 않는다.
- 결과·보고서·상담 화면은 같은 브라우저 세션의 사전진단 입력 스냅샷과 `assessment_id`를 표시한다.
- 상담 신청 제출은 네트워크 전송 없이 로컬 성공 상태만 표시한다.
- 모든 세액·비용은 합성 예시 또는 검토 상태이며 확정 세액으로 표현하지 않는다.
- 실제 개인정보, 비밀키, MCP 설정, 백엔드 연결은 포함하지 않는다.
