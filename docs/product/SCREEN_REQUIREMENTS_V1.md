# 화면 요구사항 V1

## `/`

- 표시명은 `자산승계 360`.
- 최소 90vh 다크 네이비 히어로.
- 공개 navigation에는 전문가 route를 노출하지 않는다.
- 핵심 카피: `우리 가족의 자산, 어떤 방식으로 남기는 것이 좋을까요?`
- CTA: `무료 자산승계 진단 시작`.
- 7개 전략 분기 시각화를 desktop에서 표시한다.

## `/precheck`

- client component 기반 5단계 wizard.
- 현재 단계 state, 이전/다음, 선택값 state 유지, 필수값 검증을 제공한다.
- `/precheck?step=5` 같은 query parameter로 미래 단계를 직접 열 수 없다.
- 마지막 단계에서 우선 비교 관점을 선택한 경우에만 결과 페이지로 이동한다.
- 결과 이동 시 `assessment_id`와 입력 스냅샷을 브라우저 `sessionStorage`에 저장한다.
- 단계별 질문은 서로 달라야 한다.
- 가족 단계는 배우자 유무, 성년 자녀 수, 미성년 자녀 수를 별도 사실 질문으로 받는다.
- 자산 단계는 복수 자산유형과 선택 자산별 대략 금액을 받는다.
- 채무·과거 증여 단계는 복수선택이며 `해당 없음`, `잘 모르겠음`은 상호배타다.

## `/precheck/result`

- 7개 전략 비교.
- desktop은 표, mobile 390px은 세로 카드 비교.
- 표시 항목: 현재 세금·비용, 미래 세금·비용, 총 부담, 즉시 필요현금, 부모 잔여재산, 자녀 이전재산, 납부재원 부족액, 자산 통제권, 실행 복잡도, 상태.
- 임의 점수는 사용하지 않는다.
- 보고서 CTA는 `/report-preview`로 이동한다.
- 연결된 사전진단 스냅샷이 있으면 `assessment_id`, 입력 요약, 우선 관점을 표시한다.
- 저장값이 없으면 empty state와 `/precheck` CTA를 표시한다.

## `/report-preview`

- 합성 무료 보고서 미리보기.
- 브라우저 `window.print()` 기반 PDF 저장 동작을 제공한다.
- 연결된 사전진단 요약을 표시한다.
- A4 출력 비교표는 세금·현금흐름 표와 가족 이전결과·통제권 표로 나누어 표시한다.
- 실제 Playwright `page.pdf({ format: "A4" })` 검증 대상이다.

## `/consultation`

- 사전진단 결과 ID와 입력 요약을 같은 브라우저 세션에서 실제로 읽어 표시한다.
- 수집 항목은 이름, 전화번호, 이메일 선택, 연락 가능시간, 상담 희망내용, 개인정보 수집·이용 동의.
- 이름/대표자, 전화번호, 상담 희망내용, 개인정보 동의는 필수이며 제출 전 검증한다.
- 제출 시 서버 전송 없이 접수번호와 연결된 `assessment_id`가 포함된 로컬 접수완료 상태를 표시한다.
- 개발자용 prototype 문구는 작은 footer 성격으로만 표시한다.

## `/expert/overview`

- 전문가 전용 레이아웃과 navigation.
- 프로젝트 개요, 가족·자산, 보고서 anchor 섹션을 제공한다.
- 총자산, 총채무, 순자산, 가용 현금, 납부재원 부족, 시나리오, 미해결 쟁점을 표시한다.

## `/expert/workspace`

- 전략 탭, 이벤트 타임라인, 자산·소유구조 변화, 우측 쟁점 요약, 하단 가족별 이전 결과를 제공한다.
- 검토·쟁점, 규칙·출처 anchor 섹션을 제공한다.
- 모바일에서 전문가 drawer navigation을 사용할 수 있어야 한다.
