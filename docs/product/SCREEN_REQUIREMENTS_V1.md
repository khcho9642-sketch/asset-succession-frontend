# 화면 요구사항 V1

## `/`

- 표시명은 `자산승계 360`.
- 최소 90vh 다크 네이비 히어로.
- 공개 navigation에는 전문가 route를 노출하지 않는다.
- 핵심 카피: `우리 가족의 자산, 어떤 방식으로 남기는 것이 좋을까요?`
- CTA: `무료 자산승계 진단 시작`.
- 7개 전략 분기 시각화를 desktop에서 표시한다.

## `/precheck`

- client component 기반 5단계 wizard.
- 현재 단계 state, 이전/다음, 선택값 state 유지, 필수값 검증을 제공한다.
- 마지막 단계에서만 결과 페이지로 이동한다.
- 단계별 질문은 서로 달라야 한다.

## `/precheck/result`

- 7개 전략 비교.
- desktop은 표, mobile 390px은 세로 카드 비교.
- 표시 항목: 현재 세금·비용, 미래 세금·비용, 총 부담, 즉시 필요현금, 부모 잔여재산, 자녀 이전재산, 납부재원 부족액, 자산 통제권, 실행 복잡도, 상태.
- 임의 점수는 사용하지 않는다.
- 보고서 CTA는 `/report-preview`로 이동한다.

## `/report-preview`

- 합성 무료 보고서 미리보기.
- 브라우저 `window.print()` 기반 PDF 저장 동작을 제공한다.

## `/consultation`

- 사전진단 결과 ID가 연결된 상담 신청 흐름처럼 보인다.
- 수집 항목은 이름, 전화번호, 이메일 선택, 연락 가능시간, 상담 희망내용, 개인정보 수집·이용 동의.
- 개발자용 prototype 문구는 작은 footer 성격으로만 표시한다.

## `/expert/overview`

- 전문가 전용 레이아웃과 navigation.
- 프로젝트 개요, 가족·자산, 보고서 anchor 섹션을 제공한다.
- 총자산, 총채무, 순자산, 가용 현금, 납부재원 부족, 시나리오, 미해결 쟁점을 표시한다.

## `/expert/workspace`

- 전략 탭, 이벤트 타임라인, 자산·소유구조 변화, 우측 쟁점 요약, 하단 가족별 이전 결과를 제공한다.
- 검토·쟁점, 규칙·출처 anchor 섹션을 제공한다.
- 모바일에서 전문가 drawer navigation을 사용할 수 있어야 한다.
