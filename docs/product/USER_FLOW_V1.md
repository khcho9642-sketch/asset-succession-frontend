# 사용자 흐름 V1

## 공개 방문자 흐름

1. `/`에서 자산승계 360의 서비스 목적을 확인한다.
2. `무료 자산승계 진단 시작`을 눌러 `/precheck`로 이동한다.
3. 5단계 wizard를 진행한다. URL query로 미래 단계를 직접 열 수 없고, 완료된 단계까지만 이동한다.
   - 가족
   - 자산
   - 채무·과거 증여
   - 승계 목표
   - 입력 검토·결과 준비
4. 마지막 단계에서 우선 비교 관점을 선택하면 `assessment_id`와 입력 스냅샷이 브라우저 `sessionStorage`에 저장되고 `/precheck/result`로 이동한다.
5. 결과 화면은 연결된 사전진단 요약과 7개 승계 전략을 표시한다. 저장값이 없으면 empty state와 `/precheck` CTA를 표시한다.
6. `무료 보고서 다운로드`를 눌러 `/report-preview`에서 동일 입력 요약과 브라우저 PDF 저장을 실행할 수 있다.
7. `이 결과로 조경호 회계사에게 상담하기`를 눌러 `/consultation`으로 이동한다.
8. 상담 신청 화면은 동일 `assessment_id`를 표시하고, 필수값과 동의를 검증한 뒤 네트워크 전송 없이 로컬 접수완료 상태를 보여준다.

## 전문가 흐름

1. `/expert/overview`에서 프로젝트 상태, 가족·자산 요약, 미해결 쟁점, 보고서 준비 상태를 본다.
2. 전문가 navigation은 공개 navigation과 분리된다.
3. 모바일에서는 햄버거 버튼으로 전문가 drawer를 연다.
4. `/expert/workspace`에서 전략 탭, 이벤트 타임라인, 자산·소유구조 변화, 세금·현금흐름·쟁점 요약, 가족별 이전 결과를 본다.
5. 규칙·출처는 현재 prototype 안에서 공식 근거 검토 현황 섹션으로 표현한다.

## 상태 표현

- 계산 완료
- 예상 범위
- 추가정보 필요
- 전문가 검토 필수
- 현재 조건에서는 계산 제한

상태는 별도 개발자 범례가 아니라 실제 전략 행과 카드 안에서 표시한다.
