## 기존 ID 보강

- NTS-IG-10/11: [국세청 세무서식](https://www.nts.go.kr/nts/ad/nf/nltFormatApiList.do?mi=40178&searchSe=select&selectCode=type11) 원본 연결 유지. [홈택스](https://www.hometax.go.kr/) 신고/첨부 확인 경로 추가. 증여 신고 안내 본문도 확인했다. 실제 로그인 신고 미실행.
- NTS-CG-01: 국세청 양도소득세 원본 서식/첨부 유지, 홈택스의 자산별 신고와 지방세 별도 절차 구분. 개인 신고 결과 검증 아님.
- NTS-CG-15: [위택스](https://www.wetax.go.kr/) 개인지방소득세 경로 추가. 공개 사이트는 JS가 필요하며 인증 후 신고 미실행. 기존 납부서를 신고서 전체로 표시하지 않는다.
- P6-01: [하나은행 상속예금 안내](https://www.kebhana.com/cont/news/news01/news0101/1424358_118324.jsp)의 대상별 서류 표를 확인. 민간 은행 자료이며 타 은행 공통서식으로 표시하지 않는다.
- P6-04: [한국예탁결제원 주주서비스](https://ta.ksd.or.kr/) 연결 유지/보강. 명의개서대리인 업무와 증권사 계좌 이전을 구별. 증권사별 실제 접수·서류 및 KSD 인증 업무 미검증.

가업승계 가이드의 [국세청 컨설팅 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=239011&mi=40595)에는 2026년 한시 중단 공지가 있어 신청 가능한 서비스로 표시하지 않는다.

원자료의 기존 출처 확인일은 보존한다. `editorialReview.date`는 이번 화면/분류 검토일로, 서식 개정일이나 인증 업무 검증일이 아니다.

동대문구 증여계약서 DD-G-01 계열은 보존된 원본 내장 미리보기의 '증여 대상 부동산의 표시', 소재지/토지/건물/등기목적 항목을 확인해 부동산 분류로 한정했다. 현금 등 자산 공통으로 노출하지 않는다.
