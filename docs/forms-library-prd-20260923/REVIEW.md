## 변경 및 수량 대사

원본 매니페스트 177건, 분리 문서 포함 200건, 기존 공개 191건을 출발점으로 한다.
`191 - 제외 13 + 신규 공식 자료/경로 8 + 기존 서비스 편입 5 = 공개 고유 자료 191`.
보관 9건, 제외 13건을 포함한 내부 ID는 213개다. 서비스의 생전/사후 맥락 18개는 고유 서비스 12개에 매핑된다. 그중 7개는 기존 ID를 재사용한다. 준비노트는 계속 제거 상태다.

`change-ledger.json`은 실제 적용 데이터에서 생성한 전체 ID별 변경표다. 기존 `classification`을 법적 검증 완료로 올리지 않고, 표시용 편집 검토 상태를 별도로 기록한다. 원본 메타데이터와 바이너리를 수정하지 않는 overlay 방식이다.

## 검증 구분

- `npm run test:forms`: 기존 97개 + 신규 PRD 16개 = 113개 검사. 별도 taxonomy validator 포함. 기존 바이너리 보존 검사를 삭제하지 않았다.
- `npm run test:simple-calculator`: 기존 계산기 140개 통과. 계산 코드 변경 없음.
- `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test:forms-routes`: 최종 실행 결과는 PR의 배포 검수 기록에 첨부한다.
- 기존 182개 hosted 경로, 74개 실제 PNG 및 74-member ZIP의 원본 동일성 검사를 유지했다. 이것은 기관의 현행 제출 적합성을 새로 검증했다는 뜻이 아니다.
- 40개 HWP 내장 이미지와 원본 hash 연결, 문서 분리 21개 section 연결 검사를 유지했다.
- 바뀐 검사: 상단 반복 내부 집계 UI 제거에 맞춰 현재 검색 결과 집계를 검증한다. 5개 가이드와 제외 자료 정책을 반영했다. 기존 원자료 수량·해시·파일 검사는 그대로다.
- 브라우저와 Preview 검수는 자동 단위시험과 구분하며, 최종 URL·배포 SHA·실제 확인 결과는 PR 댓글과 제출 보고에 기록한다. 아래 표는 배포 전 구현/데이터 검사 기록이다.

## 남은 제한

1. 기관 사이트 로그인 이후 개인 조회·신고·발급 및 대리인 접수는 실행하지 않았다. 서비스 경로/인증 안내 확인과 실제 민원 처리는 다르다.
2. `NTS-CG-10`, `NTS-CG-11`, `NTS-CG-12`는 기존 분류를 유지하되 원문 적용 조건 추가 검토 상태다. 빈 태그를 공통으로 자동 승격하지 않는다.
3. 기존 18개 서비스 맥락은 유실 없이 보존했지만 모든 기관 요건을 이번 날짜로 일괄 재확인했다고 표시하지 않는다.
4. 신규 원본을 임의 재작성하거나 재배포 허용을 추정하지 않았다. 제공처 링크는 다운로드 버튼과 구별한다. LIB-ADD-08 PDF는 공식 제공처가 전송한다.
5. 개인별 법정 기한 계산, 로그인 대행, 신고/발급 자동 실행은 제공하지 않는다.

## 유지관리

자료실 담당자가 신규 기관 URL의 변경·신청 중단·첨부 개정·구비서류 변경을 우선 확인한다. HTTP 성공만으로 내용을 재검증한 것으로 처리하지 않는다. 확인일/개정일은 분리하고, 실제 확인한 기관 원문 및 제한을 변경표/이 파일에 기록한다.
