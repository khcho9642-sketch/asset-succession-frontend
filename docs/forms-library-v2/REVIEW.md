# 서류 자료실 v2 검토 안내

원자료의 출처와 기존 파일을 보존하면서, 하려는 일에 맞춰 자료를 찾고 상담 전에 사실을 정리할 수 있도록 변경했습니다.

## 확인할 화면

| 주소 | 확인할 내용 |
|---|---|
| `/forms` | 조건 없는 전체 목록, 대표 자료 103개, 원자료 177개, 별도 준비자료 6개 |
| `/forms?stage=S2` | 방법·재원 설계 단계와 자체 준비자료 |
| `/forms?purpose=inheritance,gift&asset=real_estate` | 상속 또는 증여이면서 부동산인 원자료를 판정한 뒤 묶기 |
| `/forms?kind=worksheet&delivery=inline` | 파일 자료 집계와 분리된 화면 작성용 준비자료 |
| `/forms?resource=P1-22` | 후견 자료의 부모 상세, 확인된 첨부자료 안내 |
| `/forms?resource=P3-05` | 민간 현금 증여계약서 제공처와 자료 성격 |
| `/forms?resource=P8-02` | 특정 상속회복 소장 예시의 적용 범위 |
| `/forms?resource=P9-07` | 상속 명의변경 의결사례, 전용 신고서 미확인 표시 |
| `/forms/planning` | 준비자료 6개와 각 자료의 작성 목적 |
| `/forms/planning/PLAN-04` | 금액 입력·검토·텍스트 저장·인쇄 |
| `/forms/planning/PLAN-06` | 선택한 준비자료를 검토한 뒤 상담 요약으로 모으기 |
| `/precheck?purpose=inheritance` | 선택한 목적·시점을 관련 서류 보기로 전달 |

## 동작 기준

- 같은 필터 축은 OR, 다른 축은 AND입니다. 서로 다른 자식 자료가 각 조건을 나누어 만족하는 묶음은 결과에 포함하지 않습니다.
- 84개 독립 자료와 19개 탐색 묶음이 대표카드 103개입니다. 묶음에 원자료 62개, 부모 상세에 부표·사례·참고 22개, 보관 9개가 배치됩니다. 총 원자료는 177개입니다.
- 썸네일과 제목은 내부 상세로 연결됩니다. 파일 버튼에는 실제로 제공하는 형식과 파일만 나옵니다. 기존 74개 자료·148개 파일 ZIP은 최신 서비스 Preview의 바이트를 유지합니다.
- 단계는 자유 탐색입니다. 직접 `/forms`에 들어오면 모든 조건이 비어 있습니다. 상담에서 명시적으로 넘어올 때만 목적·확인된 시점을 전달합니다.
- 일반 탐색 표기는 `상속`으로 통일했습니다. `상속재산분할협의서` 같은 실제 서식명과 기존 출처 분류는 보존합니다.
- 자체 준비자료는 전송 없이 작성하고 복사·다운로드·인쇄할 수 있습니다. 법정 서식이나 세금 계산 결과로 표시하지 않습니다.

## 데이터와 확인 범위

- 수집 작업 완료와 원본 파일 확보를 구분합니다. 제공처 링크만 확인한 항목에는 임의 파일을 만들지 않습니다.
- 새 스키마는 기존 레코드의 `resource`에 추가합니다. 기존 `deadline` 문자열과 원본 파일 경로를 보존합니다. 이후 서비스에 반영된 74개 실제 썸네일과 `preview` 정보는 별도 근거로 통합하며, 최초 보존 기준 파일은 수정하지 않습니다.
- 제공받은 두 JSON Schema는 수정하지 않았습니다. 사건별 기한 스키마는 포함하지만 검증되지 않은 법정 기간이나 D-day 계산을 활성화하지 않았습니다.
- `stage_ids`, 목적·시점, 대표카드 배치는 제공된 배치표를 따릅니다. 법적 적용 가능성을 자동 확정하지 않으며, 미검토 분류는 검토 상태를 표시합니다.
- P8-07의 진단서는 의료기관용 공통 법정 양식 참고로 구분합니다. 후견 전용 양식 또는 모든 법원에서 수리되는 서류라고 표시하지 않습니다.
- 민간 서식, 기관 사례, 공식 전자문서 입력 경로를 구분합니다. 수집 근거는 `docs/forms-expansion-109/evidence/round16`에서 확인할 수 있습니다.

## 검증

`python -m pip install jsonschema==4.26.0` 후 `npm ci`를 실행합니다.

```sh
npm run test:forms
npm run test:simple-calculator
npm run lint
npm run build
npm run typecheck
npm run test:forms-routes
npm run test:chat
```
