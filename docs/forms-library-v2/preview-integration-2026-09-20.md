- 목적·자산·자료유형·이용방식 필터, S1–S7 단계, 부모 상세·묶음 펼치기, 준비자료 6종을 포함합니다.

## 배포 후 확인할 동작

화면별 주소와 확인 기준은 [REVIEW.md](REVIEW.md)를 따릅니다. 배포 커밋이 이 통합 브랜치의 최종 커밋인지 먼저 확인합니다.

1. `/forms` 직접 진입 시 조건 없이 대표카드 103개와 원자료 177개가 표시되는지 확인합니다.
2. 같은 필터 축의 복수 선택은 OR, 서로 다른 축은 AND로 동작하는지 확인합니다. 묶음은 하나의 원자료가 모든 조건을 만족해야 노출합니다.
3. S1–S7 자유 이동, 생전·사후 분기, 새로고침과 뒤로 가기의 선택 상태를 확인합니다.
4. 썸네일·제목의 내부 상세, 실제 형식별 파일 선택, 묶음과 부모 상세를 확인합니다.
5. 원본 썸네일의 가로세로 비율과 작은 이미지 안내를 PC·모바일에서 확인합니다.
6. 준비자료 입력·요약·복사·저장과 PLAN-06의 선택한 자료 모으기를 확인합니다. 테스트에는 가상 정보만 사용합니다.
7. 기존 계산기와 모바일 내비게이션을 함께 확인합니다.

배포와 실제 브라우저 검수가 끝나기 전에는 기존 Preview의 검사 결과를 이 통합본의 결과로 사용하지 않습니다. 검토 후 운영 반영 여부를 결정합니다.
