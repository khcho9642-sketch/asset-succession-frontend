# 남은 11개 원본 재조사

확인일: 2026-09-27. 기준: `899a0f2199ac1d7ee91bb92511e3fc8d60934855`.
기존 33건 조사에서 원본을 연결하지 못했던 **11건만** 재조사했다. 이전 22건의 파일과 분류는 보존했다.

## 결과

- **8건 연결**: 원본 16개(PDF 8개, HWP 8개). 15개는 무수정 원본을 사이트에 등록하고, 산재 HWP 1개는 정상 작동하는 국가법령정보센터 다운로드에 연결했다.
- **3건 미확보**: 기여분 결정, 상속회복청구, 포괄 명칭의 후견인 권한 초과행위. 다운로드 불가·서식 부존재로 확정하지 않는다.
- 문서 수·분류·관계는 유지: 공개 198건(서식 151 / 조회·발급 25 / 안내 22), 보관 9, 제외 13.
- 실제 제공하는 고유 원본: 사이트 182 → 197개, 외부 직접 연결 22 → 23개. 자료 카드 수와 파일 수는 다르다.
- 사이트 미리보기 7개는 확보한 PDF 첫 페이지를 렌더링했다. 산재는 실제 열린 근로복지공단 원본 뷰어로 연결했다. 문서 내용을 다시 만들거나 가짜 이미지를 생성하지 않았다.

파일별 URL·크기·SHA-256·확인 시각·방법과 11건 각각의 시도 경로는 [sources.json](./sources.json)에 기록했다. 브라우저 다운로드는 HTTP 상태가 노출되지 않아 상태 200을 추정하지 않았다.

## 미확보 3건의 구체적 사유

### P1-19 기여분 결정 청구서

1. [전자소송포털 양식모음](https://ecfs.scourt.go.kr/psp/index.on?m=PSP720M24)의 정상 브라우저 검색 `기여분`: 0건.
2. [대한법률구조공단 법률서식 검색](https://www.klac.or.kr/legalinfo/legalFrm.do?pageIndex=1&folderId=000&listNm=%EC%A0%84%EC%B2%B4&searchCnd=0&searchWrd=%EA%B8%B0%EC%97%AC%EB%B6%84&scdFolderId=): 0개 게시물, 내용 없음.

두 공식 검색 범위에서 대응 첨부를 찾지 못했다. 일반 분할·분리 양식, 민간 블로그 작성본을 기여분 결정 원본으로 표시하지 않았다. 관할 가정법원 또는 법률구조공단에 사건에 맞는 서식 제공 여부를 확인하는 것이 다음 경로다. 접속 장애 때문이라는 종전 사유는 현재 설명에서 제거했다.

### P8-02 상속회복청구 소장

1. [전자소송포털 양식모음](https://ecfs.scourt.go.kr/psp/index.on?m=PSP720M24) 정상 브라우저 검색 `상속회복`: 0건.
2. [대한법률구조공단 법률서식 검색](https://www.klac.or.kr/legalinfo/legalFrm.do?pageIndex=1&folderId=000&listNm=%EC%A0%84%EC%B2%B4&searchCnd=0&searchWrd=%EC%83%81%EC%86%8D%ED%9A%8C%EB%B3%B5&scdFolderId=): 0개 게시물, 내용 없음.

상속권 침해 회복에 대응하는 원본 미확보다. 종전 조사에서 발견한 진정명의회복 소장은 다른 청구원인의 서식이므로 연결하지 않았다. 공단 법률서식 담당 또는 관할 법원에 대응 원문을 확인해야 한다. 공식 파일이 어디에도 없다는 결론이 아니다.

### P8-10 후견인 권한 초과행위 허가 청구서

1. [서울가정법원 후견과 각종 양식](https://sladmin.scourt.go.kr/slfamily/civil_complaint/civil_06/index_03.html): 성년후견 목록 31개를 정상 열람. 거주 건물·대지 매도허가, 법정대리권 범위변경, 후견감독인의 동의를 갈음하는 재판 등은 각각 다른 양식이다.
2. 전자소송포털의 `후견` / `허가` 결과에도 행위·권한별 청구서가 구분되어 있다.
3. [공단 권한초과 검색](https://www.klac.or.kr/legalinfo/legalFrm.do?pageIndex=1&folderId=000&listNm=%EC%A0%84%EC%B2%B4&searchCnd=0&searchWrd=%EA%B6%8C%ED%95%9C%EC%B4%88%EA%B3%BC&scdFolderId=)의 1192 HWP를 실제 수신하여 본문 확인: 친권자 또는 후견인의 **임무대행자로 선임된 사람**, 계속 중인 친권자 지정 본안, 미성년자에 관한 작성사례다.

후견 유형·허가받을 행위가 특정되지 않은 포괄 카드에 위 파일 하나를 무차별 적용하지 않았다. 현재 명칭과 동등한 단일 원본은 미확보다. 서울가정법원 목록에서 해당 행위를 먼저 확인하는 경로를 남겼다.

## 접속 오류와 파일 확보의 구분

- 전자소송포털: 지난 자동 접속 차단과 달리 이번 정상 브라우저에서 검색 가능. 관측한 첨부 식별자로 공식 `file.scourt.go.kr` 원본 수신 성공.
- 인터넷등기소: 자동 HTTP 연결 오류와 달리 정상 브라우저 첨부 버튼으로 6개 수신 성공. 세션형 다운로드이므로 첨부 직링크를 추측하지 않고 실제 수신 원본을 등록.
- 사학연금: 자동 요청은 웹 방화벽 HTTP 400, 정상 브라우저 PDF는 수신 성공. 원본 PDF를 기준으로 등록.
- 근로복지공단: 게시물과 PDF 뷰어 정상. 다운로드는 권한 안내 HTML이므로 PDF로 간주하지 않음. 별도 공식 출처인 국가법령정보센터에서 동일 별지의 HWP 확보.

## 원본·권리·검증 범위

- 법원 공개 서식은 [대한민국 법원 저작권보호정책](https://www.scourt.go.kr/portal/popup/jeojak_pop.html)에 따라 출처를 표시하고 원본 무수정으로 제공. 다운로드 형식별 내용·개정 시점까지 동일하다고 주장하지 않는다.
- 사학연금 게시물의 **공공누리 제1유형** 표시를 직접 확인하고 출처·원본을 유지.
- 산재 HWP는 공식 서버 직접 링크, 미리보기는 공단 뷰어 링크로만 제공. 공단 PDF를 자체 PDF로 재제작하지 않음.
- 원본 수신·형식·열림·제목·SHA-256 검증과 개별 사건 법적 적용 검증은 다르다. 모든 관련 자료의 검토 상태는 `partial` 유지.
- 기존 파일·ZIP·자료 ID·분류·연결관계를 삭제하거나 재작성하지 않았고 계산기·메인·채팅·MCP는 수정하지 않았다.
