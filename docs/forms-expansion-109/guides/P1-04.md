# P1-04 협의분할 상속 소유권이전등기 신청서

확인일: 2026-09-20. 기존 `REG-I-03`의 출처 URL만 교체하며 기존 자료 ID·다운로드·원본·ZIP을 유지합니다.

[법제처 찾기쉬운 생활법령정보의 상속등기 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=3&cnpClsNo=3&csmSeq=566&popMenu=ov)에서 `협의분할 상속 소유권이전등기 신청서` 또는 같은 제목의 `(구분건물)` 파일을 선택하세요. 단순 상속등기 신청서와 구분합니다.

기존 수집 기록의 일반·구분건물 HWP 2개를 공식 제공처에서 다시 받아 본문 제목·협의분할 기재·크기·SHA-256 일치를 확인했습니다. 법제처의 공식 제공 페이지이며 인터넷등기소 직링크로 표시하지 않습니다. 검증용 파일을 새로 재배포하거나 신청서·협의서 내용을 재작성하지 않았습니다.

원본 동일성과 현재 사건의 제출 적합성은 다른 확인입니다. 협의·첨부서류 요건은 관할 등기소에서 확인하세요. 인쇄 레이아웃은 미검수이며 미확인 기한·개정일은 추가하지 않았습니다.
