인계일: 2026-09-20. 원래 공식 목록 확인일: 2026-09-19.

[대한민국 법원 인터넷등기소](https://www.iros.go.kr/index.jsp)의 고객센터 > 지원안내 > 등기신청양식에서 `매매`를 검색하고 `04-2.매매로인한소유권이전등기신청(구분건물)`을 선택합니다.

기존 작업의 공식 화면 검증 기록에서 HWP·PDF·DOCX·ODT 첨부 표시와 파일명을 확인했습니다. 화면이 단일 주소를 사용하므로 검색 결과별 직접 URL을 제공하지 않습니다.

**원본 바이너리는 미확보입니다.** 이번에는 기존 검증 기록과 이용 경로만 요청 브랜치에 인계했습니다. 첨부 형식 표시 확인은 원본 다운로드·본문·해시 검증과 다릅니다. 기관 원본을 재작성하거나 사이트에 재배포하지 않았으며, 공식 제공처에서 파일을 받아야 합니다.

이번 자동 HTTP 재접속은 서버가 연결을 종료하여 실패했습니다. 현재 다운로드 성공으로 표시하지 않으며, 완료 근거는 인계한 2026-09-19 공식 브라우저 목록 검증입니다.

일반건물 신청서와 구분건물 신청서를 구분하고, 실제 제출 요건은 관할 등기소에 확인하세요. 별도 기한이나 개정일은 추정해 등록하지 않았습니다.
