# P0-10 특별한정승인 심판청구서

확인일: 2026-09-20. 기관 원본을 재작성한 서식이 아닌 이용 안내입니다.

- [대한민국 법원 전자소송포털 양식모음](https://ecfs.scourt.go.kr/psp/index.on?m=PSP720M24)에서 `한정승인`을 검색하고 `상속한정승인 심판청구서`를 선택합니다.
- 해당 공용 원본 안에 일반한정승인·특별한정승인의 청구원인과 상속재산목록이 있습니다. 별도 특별한정승인 전용 파일을 새로 만든 것이 아닙니다.
- 본인에게 해당하는 요건·기산점·제출자료는 법원에 확인하세요. 이번 작업에서 별도 법정 기한이나 D-day를 등록하지 않았습니다.

기존 수집 증거를 인계하고 공식 HWP를 다시 받아 본문 제목, 크기 및 SHA-256 일치를 확인했습니다. 인쇄 레이아웃·개별 사건의 제출 적합성은 검수하지 않았습니다. 원본 바이너리는 로컬 검증용으로만 보관하고 공개 재배포하지 않습니다.
