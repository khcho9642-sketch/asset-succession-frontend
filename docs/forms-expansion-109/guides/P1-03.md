# P1-03 상속 소유권이전등기 신청서

확인일: 2026-09-20. 이 항목은 기존 `REG-I-01`의 출처 주소만 교체합니다. 기존 다운로드·자료 ID·파일·ZIP은 그대로입니다.

[법제처 찾기쉬운 생활법령정보의 상속 소유권이전등기 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=3&cnpClsNo=3&csmSeq=566&popMenu=ov)에서 `상속 소유권이전등기 신청서` 또는 `상속 소유권이전등기 신청서 (구분건물)`을 선택하세요.

공식 페이지의 두 HWP를 다시 받아 문서 제목·본문, 크기, SHA-256을 기존 검증 기록과 대조했습니다. 인터넷등기소 직링크가 아니라 법제처 공식 제공 페이지입니다. 이번에 추가 확보한 검증용 원본은 공개 재배포하지 않습니다.

이 확인은 파일 존재와 원본 동일성에 관한 것입니다. 현행 제출 요건·개별 사건의 적합성·인쇄 레이아웃까지 검수한 것은 아니며 관할 등기소 확인이 필요합니다. 미확인 서식 개정일·신청 기한을 추정하여 입력하지 않았습니다.
