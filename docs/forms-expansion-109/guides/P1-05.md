# P1-05 증여 소유권이전등기 신청서

확인일: 2026-09-20. 기존 `REG-G-01`의 출처 URL만 교체합니다. 새 중복 카드나 서식 파일을 만들지 않고 기존 다운로드·자료 ID·원본·ZIP을 보존합니다.

[법제처 찾기쉬운 생활법령정보의 증여 소유권이전등기 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=2&cnpClsNo=3&csmSeq=566&popMenu=ov)에서 일반 신청서 또는 `(구분건물)` 신청서를 선택하세요. 연결된 출처는 법제처이며 인터넷등기소 직링크가 아닙니다.

두 HWP를 공식 첨부 주소에서 다시 받아 소유권이전등기신청 제목·증여 기재·크기·SHA-256을 기존 기록과 대조했습니다. 검증용 바이너리는 이번에 공개 재배포하지 않습니다. 양식의 조항·예시를 재작성하거나 바꾸지 않았습니다.

원본 동일성 확인과 현재 거래의 제출 적합성 검수는 구분합니다. 관할 등기소에서 해당 거래의 첨부서류·요건을 확인하세요. 인쇄 레이아웃은 미검수이며 기한·개정일은 미확인 값을 유지합니다.
