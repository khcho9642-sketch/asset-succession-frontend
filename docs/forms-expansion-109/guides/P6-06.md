# P6-06 퇴직연금(DB·DC·IRP) 상속 수령 안내

확인일: 2026-09-19T15:42:18.200221Z
제공 방식: 공식 제공처 안내. 이 파일은 기관 서식 원본이 아닌 출처 확인 메모입니다.

고용노동부 「근로자퇴직급여보장법 질의회시집」의 사망 상속 청구 안내입니다. DB는 사전 확정 급여를 회사·퇴직연금사업자와 확인하고, DC는 개인별 적립금과 운용손익을 확인합니다. 책자 825쪽은 DB·DC 가입자 사망 시 상속 법리에 따른 일시금 지급을, 824쪽은 기존 IRP 적립금 상속 청구를 설명합니다. IRP 청구 시 사망사실확인서·가족관계증명서·위임 시 위임장 등을 준비해 가입 금융기관을 방문합니다. DB·DC의 지급신청서와 추가 제출서류, 공동상속인 분할·대표청구 방식은 회사 및 가입 금융기관에 확인하세요. 610쪽에는 회사가 DB 급여 전액을 직접 지급한 사례도 수록되어 있습니다. 2024년 발간 자료(2022년 1월까지의 질의회시)이며, 배우자 연금계좌 승계·과세 특례는 별도 확인이 필요합니다.
