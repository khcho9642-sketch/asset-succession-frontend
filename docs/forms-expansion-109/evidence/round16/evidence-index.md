## 보존 기준

- `support/{ID}.json`은 원출처 URL, 확인 시각, 응답·파일 해시, 서식명 또는 짧은 본문 발췌를 담는다. 각 적용 기록의 `source_evidence.evidence_sha256`은 해당 근거 요약 파일의 해시다.
- `capture_sha256`은 수집 당시 전체 검증 기록을 식별하는 값이고, `sha256`은 해당 응답 또는 원본 파일의 해시다. 원본 수집 기록 전체와 원문 바이너리를 이 폴더에 포함한다는 뜻은 아니다.
- 정규화한 적용 기록과 `support/`에서 임시 작업 디렉터리, 쿠키·응답 헤더, 전체 HTML·본문 텍스트, 관련 없는 검색 결과, 실행 가능한 미리보기 링크를 제외했다. 원시 `klac-browser-evidence.json`은 이 색인의 공개 근거에 포함하지 않으며 커밋 대상에서도 제외한다.
- 이 정리 작업에서는 HWP·PDF 바이너리를 새로 복사하지 않았다. 기존에 원본 제공이 허용된 P2-11·P2-15의 저장소 경로는 유지했다.
- 등기소 검색 화면은 주소가 `index.jsp`로 유지되므로 공식 메뉴 경로·검색어·서식명·첨부명을 함께 기록했다. 이 세 건은 파일 바이트나 본문을 검증한 것으로 표시하지 않는다.
- P3-05는 민간 제공처, P8-02·P9-07은 사례 범위를 그대로 보존한다. 법정 기한·금액을 새로운 구조화 필드나 화면 설명으로 추가하지 않았다.
