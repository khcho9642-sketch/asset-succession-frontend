# Vercel 무료 크레딧으로 채팅 시험

> 이전 연결의 시험 기록이다. 2026-09-09 사용자 요청으로 Google Gemini Developer API 직접 연결로 전환했다. 현재 설정은 [구글 무료 채팅 시험 안내](google-free-chat-trial.md)를 따른다. 아래 Gateway 모델·키·OIDC는 현재 채팅 코드에서 사용하지 않는다.

목표는 `CHAT_GUIDE.md`에 따른 가상 상담을 Vercel AI Gateway의 무료 크레딧으로만 시험하는 것이다. 크레딧 구매, 자동 충전, BYOK, 유료 모델로의 전환은 이 작업의 범위에 없다.

## 현재 상태

- 가이드 RUNTIME 구간을 서버 프롬프트에 연결했다. 지침이 없거나 마커가 잘못되면 AI 요청을 시작하지 않는다.
- 일반 배포에서는 `AI_DIAGNOSIS_FREE_TRIAL_ENABLED`가 공백 제거 후 소문자 `true`일 때만 활성화한다. 사용자가 승인한 시험 Preview 브랜치에는 아래의 한정된 기본 설정을 적용한다.
- 정적 Gateway 키가 없으면 AI SDK의 Vercel OIDC 인증을 사용할 수 있다. 인증 정보는 서버에만 둔다.
- 2026-09-09 운영자가 카드 등록과 Preview 환경변수 저장을 완료했다고 알렸다. 무료 잔액 `Free` 및 자동 충전 꺼짐을 조건으로 설정을 안내했다. 관리 연결의 프로젝트 조회는 `403 Forbidden`, 팀 목록은 빈 배열이어서 계정 화면을 직접 확인하거나 환경변수를 대신 저장하지는 못했다.
- 저장된 설정을 반영하는 새 Preview 배포에서 실제 AI 응답을 확인한다. 카드 등록이나 환경변수 저장만으로 응답 검증이 끝났다고 판단하지 않는다.
- 아래 활성화 스위치는 운영자가 확인 후 켜는 장치다. 무료 잔액이나 결제 상태를 자동 검증하는 기능이 아니다.

## 활성화 전에 확인

대상 프로젝트가 속한 **동일한 Vercel 팀**의 AI Gateway 화면에서 확인한다.

1. 크레딧 표시가 `Free`인지 확인한다. 과거 크레딧 구매로 유료 티어가 된 계정이면 이번 무료 시험을 켜지 않는다.
2. 크레딧 창의 자동 충전이 꺼져 있는지 확인한다. 결제·크레딧 구매 버튼은 누르지 않는다.
3. 현재 `Free Tier` 대상이며 `tool calling`을 지원하는 텍스트 모델 한 개를 고른다. 모델 ID와 확인 날짜를 기록한다. 전체 모델 목록에 있거나 가격이 저렴하다는 이유만으로 무료 티어 대상이라고 판단하지 않는다.
4. 별도로 청구되는 유료 기능이나 계정 라우팅 규칙이 이번 시험에 적용되지 않는지 확인한다. 계정 상태를 확인할 수 없으면 비활성을 유지한다.
5. `CHAT_GUIDE.md` 6.3의 부분정보 보존 등 미완료 사항을 확인한다. 최초 시험은 가상 사례로 진행하며 검증 전 실제 고객 서비스를 시작하지 않는다.

2026-09-09 확인한 공식 가격 문서에 따르면 무료 티어는 매월 $5이며 일부 모델만 대상이다. 한 번 크레딧을 구매하면 유료 티어로 전환되고 월 무료 크레딧은 더 이상 적용되지 않는다. `/v1/credits`의 `balance`와 `total_used`에는 무료/구매 잔액 구분이나 자동 충전 상태가 없다. 이 API의 잔액만으로 무료 사용 조건을 검증할 수 없다.

## 확인 후 서버 환경변수

먼저 검토용 Preview 배포에만 설정한다. 아래 표의 설명 문장을 값으로 복사하지 않는다.

| 이름 | 값 / 조건 |
| --- | --- |
| `AI_DIAGNOSIS_MODEL` | 위에서 확인한 무료 티어 대상 모델의 정확한 `provider/model` ID |
| `AI_DIAGNOSIS_FREE_TRIAL_ENABLED` | 모든 계정 확인을 마친 뒤 `true`; 중단 시 `false` |
| `VERCEL_OIDC_TOKEN` | Vercel이 제공하는 서버 인증. 수동으로 문서·Git·브라우저 코드에 복사하지 않는다. |
| `AI_GATEWAY_API_KEY` | OIDC 시험에서는 미설정. 이미 존재하면 SDK가 이 키를 우선 사용하므로 해당 키의 팀과 결제 조건을 별도로 확인한다. |

2026-09-09 시험 설정:

```env
AI_DIAGNOSIS_MODEL=openai/gpt-5.4-mini
AI_DIAGNOSIS_FREE_TRIAL_ENABLED=true
```

적용 범위는 Preview의 `codex/chat-opening-topics` 브랜치다. 모델은 같은 날 [Vercel Free Tier 모델 목록](https://vercel.com/ai-gateway/models?freeTier=true)의 `availableToFreeTier: true` 및 `tool-use`를 확인해 선택했다. 무료 크레딧을 사용하는 모델이며 무제한·영구 무료 모델이라는 뜻은 아니다. 이후 다른 모델로 바꿀 때는 무료 대상 여부를 다시 확인한다.

최초 `google/gemini-2.5-flash-lite` 시험에서는 상속 응답과 사실 카드가 생성됐으나, 다른 가상 사례에서 동일 도구의 반복 호출, 도구 결과 없는 오류 종료, 답변만 생성되고 사실 카드가 빠지는 문제가 관찰됐다. 이후 `openai/gpt-4o-mini` 시험에서는 증여 답변과 사실 카드 3개가 생성됐지만, 검증되지 않은 잘못된 증여세 기준을 확정하고 고객이 기억하지 못한다고 한 과거 금액을 다시 묻는 문제가 나타났다.

이 흐름과 답변 품질을 다시 시험하기 위해 같은 날 무료 티어 대상 및 도구 지원을 확인한 `openai/gpt-5.4-mini`로 단일 모델 설정을 수동 변경했다. `CHAT_GUIDE.md` 앞부분에는 현재 검증된 세금 계산 결과가 없다는 점과 모르는 항목을 즉시 재질문하지 않는 기존 정책을 우선 규칙으로 강조했다. 요청 실패 시 다른 모델을 호출하는 자동 전환은 없다. 새 모델의 실제 응답과 카드 생성은 배포 후 가상 사례로 다시 확인한다.

모델 환경변수가 명시되어 있으면 그 값이 계속 우선한다. 기존 Gemini나 GPT-4o mini 값이 배포에 전달되는 경우에는 그 값을 수정해야 하며, 기본값 변경으로 덮어쓰지 않는다.

서버 설정 후 새 Preview 배포에 적용되었는지 확인한다. `GET /api/diagnosis`의 `configured: true`는 가이드와 설정이 준비되었다는 뜻이며, 모델 응답·무료 잔액·대화 품질을 검증했다는 뜻은 아니다.

코드는 한 개 모델만 호출하며 모델 대체 목록이나 타 서비스 결제 경로를 추가하지 않는다. SDK 재시도는 0회, 한 턴은 사실 제안과 답변의 최대 2단계다. 출력·요청 크기·요청 시간 제한을 유지한다. 앱은 크레딧을 구매하거나 자동 충전을 설정하지 않는다.

## 승인한 Preview에 한정된 시험 기본값

운영자가 설정 저장을 완료했다고 알린 뒤 새 배포를 확인했으나, `/api/diagnosis`가 `FREE_TRIAL_NOT_ENABLED`와 `MODEL_MISSING`을 반환했다. 인증 경로와 가이드는 준비되어 있었지만 두 환경변수가 배포에 전달되지 않았다.

승인된 무료 시험을 진행하기 위해 코드의 비밀이 아닌 설정에 한정된 기본값을 둔다.

- `VERCEL_ENV=preview`와 `VERCEL_GIT_COMMIT_REF=codex/chat-opening-topics`가 모두 정확히 일치해야 한다.
- 위 조건에서 활성화 변수가 아예 없으면 `true`, 모델 변수가 아예 없으면 `openai/gpt-5.4-mini`를 적용한다.
- 명시한 `false`, 빈 값, 잘못된 모델 값은 기본값으로 덮어쓰지 않는다. 중단할 때는 해당 Preview 환경의 활성화 변수를 `false`로 설정하고 다시 배포한다. 코드의 시험 기본값도 제거할 수 있다.
- 다른 Preview 브랜치, Production, 로컬에서는 이 기본값을 사용하지 않는다. 배포 환경이나 Git 브랜치 정보가 없을 때도 일반 설정을 요구한다.
- Vercel 계정의 결제·권한·크레딧·인증 설정은 변경하지 않는다. SDK 재시도나 다른 모델로의 자동 전환도 추가하지 않는다.

`GET /api/diagnosis`는 `configured`와 문제 코드 배열 `issues`를 반환한다. 실제 설정 값·모델명·토큰·키·파일 경로는 반환하지 않으며, 이 확인 요청은 외부 AI를 호출하지 않는다. 문제 코드가 없어도 실제 모델 응답은 별도로 시험한다.


## 가상 상담 확인과 중단

- 네 주제 버튼과 자유 입력으로 짧게 시험하고 Vercel 화면에서 무료 크레딧 차감 여부를 확인한다.
- `CHAT_GUIDE.md` 6.4의 대화 품질 사례를 점검한다. 이미 알려준 내용 재질문, 사실 누락, 모르는 값의 임의 확정, 계산 결과 생성 여부를 본다.
- 크레딧 부족·권한 오류·호출 한도 오류가 나면 다른 유료 모델로 전환하지 않고 시험을 중단한다. 화면의 직접 입력 기능은 계속 사용할 수 있다.
- 팀·키·모델·크레딧 티어·자동 충전 등 계정 조건이 바뀌면 스위치를 `false`로 바꾸고 다시 확인한다. 운영 중 결제 설정 변경을 앱이 자동 탐지하는 기능은 없다.
