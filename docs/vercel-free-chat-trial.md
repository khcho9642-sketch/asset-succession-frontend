# Vercel 무료 크레딧으로 채팅 시험

목표는 `CHAT_GUIDE.md`에 따른 가상 상담을 Vercel AI Gateway의 무료 크레딧으로만 시험하는 것이다. 크레딧 구매, 자동 충전, BYOK, 유료 모델로의 전환은 이 작업의 범위에 없다.

## 현재 상태

- 가이드 RUNTIME 구간을 서버 프롬프트에 연결했다. 지침이 없거나 마커가 잘못되면 AI 요청을 시작하지 않는다.
- `AI_DIAGNOSIS_FREE_TRIAL_ENABLED`가 정확히 `true`일 때만 AI 연결 설정을 사용할 수 있다. 기본값은 비활성이다.
- 정적 Gateway 키가 없으면 AI SDK의 Vercel OIDC 인증을 사용할 수 있다. 인증 정보는 서버에만 둔다.
- 계정 무료 티어와 자동 충전 상태는 아직 확인하지 못했다. Vercel 프로젝트 조회가 `403 Forbidden`으로 거부됐다. 환경변수·결제 설정은 변경하지 않았고 실제 추론 요청도 보내지 않았다.
- 아래 활성화 스위치는 운영자가 확인 후 켜는 장치다. 무료 잔액이나 결제 상태를 자동 검증하는 기능이 아니다.

## 활성화 전에 확인

대상 프로젝트가 속한 **동일한 Vercel 팀**의 AI Gateway 화면에서 확인한다.

1. 크레딧 표시가 `Free`인지 확인한다. 과거 크레딧 구매로 유료 티어가 된 계정이면 이번 무료 시험을 켜지 않는다.
2. 크레딧 창의 자동 충전이 꺼져 있는지 확인한다. 결제·크레딧 구매 버튼은 누르지 않는다.
3. 현재 `Free Tier` 대상이며 `tool calling`을 지원하는 텍스트 모델 한 개를 고른다. 모델 ID와 확인 날짜를 기록한다. 전체 모델 목록에 있거나 가격이 저렴하다는 이유만으로 무료 티어 대상이라고 판단하지 않는다.
4. 별도로 청구되는 유료 기능이나 계정 라우팅 규칙이 이번 시험에 적용되지 않는지 확인한다. 계정 상태를 확인할 수 없으면 비활성을 유지한다.
5. `CHAT_GUIDE.md` 6.3의 부분정보 보존 등 미완료 사항을 확인한다. 최초 시험은 가상 사례로 진행하며 검증 전 실제 고객 서비스를 시작하지 않는다.

2026-09-09 확인한 공식 가격 문서에 따르면 무료 티어는 매월 $5이며 일부 모델만 대상이다. 한 번 크레딧을 구매하면 유료 티어로 전환되고 월 무료 크레딧은 더 이상 적용되지 않는다. `/v1/credits`의 `balance`와 `total_used`에는 무료/구매 잔액 구분이나 자동 충전 상태가 없다. 이 API의 잔액만으로 무료 사용 조건을 검증할 수 없다.

## 확인 후 서버 환경변수

먼저 검토용 Preview 배포에만 설정한다. 아래 표의 설명 문장을 값으로 복사하지 않는다.

| 이름 | 값 / 조건 |
| --- | --- |
| `AI_DIAGNOSIS_MODEL` | 위에서 확인한 무료 티어 대상 모델의 정확한 `provider/model` ID |
| `AI_DIAGNOSIS_FREE_TRIAL_ENABLED` | 모든 계정 확인을 마친 뒤 `true`; 중단 시 `false` |
| `VERCEL_OIDC_TOKEN` | Vercel이 제공하는 서버 인증. 수동으로 문서·Git·브라우저 코드에 복사하지 않는다. |
| `AI_GATEWAY_API_KEY` | OIDC 시험에서는 미설정. 이미 존재하면 SDK가 이 키를 우선 사용하므로 해당 키의 팀과 결제 조건을 별도로 확인한다. |

서버 설정 후 새 Preview 배포에 적용되었는지 확인한다. `GET /api/diagnosis`의 `configured: true`는 가이드와 설정이 준비되었다는 뜻이며, 모델 응답·무료 잔액·대화 품질을 검증했다는 뜻은 아니다.

코드는 한 개 모델만 호출하며 모델 대체 목록이나 타 서비스 결제 경로를 추가하지 않는다. SDK 재시도는 0회, 한 턴은 사실 제안과 답변의 최대 2단계다. 출력·요청 크기·요청 시간 제한을 유지한다. 앱은 크레딧을 구매하거나 자동 충전을 설정하지 않는다.

## 가상 상담 확인과 중단

- 네 주제 버튼과 자유 입력으로 짧게 시험하고 Vercel 화면에서 무료 크레딧 차감 여부를 확인한다.
- `CHAT_GUIDE.md` 6.4의 대화 품질 사례를 점검한다. 이미 알려준 내용 재질문, 사실 누락, 모르는 값의 임의 확정, 계산 결과 생성 여부를 본다.
- 크레딧 부족·권한 오류·호출 한도 오류가 나면 다른 유료 모델로 전환하지 않고 시험을 중단한다. 화면의 직접 입력 기능은 계속 사용할 수 있다.
- 팀·키·모델·크레딧 티어·자동 충전 등 계정 조건이 바뀌면 스위치를 `false`로 바꾸고 다시 확인한다. 운영 중 결제 설정 변경을 앱이 자동 탐지하는 기능은 없다.
