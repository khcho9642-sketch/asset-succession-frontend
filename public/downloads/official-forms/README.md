# 기관 원본 자료 묶음

확인일: 2026-09-17

**74개 전체 자료, 총 148개 파일**을 담았습니다. 기관 원본 147개와 사이트 변환 PDF 1개입니다.
같은 자료의 HWP, Word, PDF를 각각 별도 자료로 세지 않습니다.
법원 생활속 계약서 PDF는 빈 양식·설명·예시가 함께 있는 원본입니다.
본문·표·예시를 재작성하거나 자산승계360 로고를 추가하지 않았습니다.

## 추가된 국세청 자료

- NTS-IE-01, NTS-IE-02, NTS-IE-03: 국세청 첨부 HWP 3개를 수정 없이 수록했습니다.
- NTS-CE-01: 국세청 웹 사례 본문 및 빈 서식·작성방법 이미지 5장을 묶은 PDF 1개와 원본 PNG 5개를 제공합니다. PDF는 **기관이 제공한 원본 문서가 아니라 사이트 변환본**입니다. 금액을 채워 넣거나 계산 사례를 새로 만들지 않았습니다. PDF의 첫 쪽은 원문 사례 조건이며, 다음 다섯 쪽은 이미지 원본입니다.

네 항목도 개별 다운로드와 전체 묶음에 포함됩니다. 한 자료의 여러 형식을 별도 자료로 부풀리지 않습니다.

## 출처·이용 조건

모든 파일의 기관, 원문 게시물, 실제 첨부 주소, 파일명, 크기, SHA-256 및 점검 범위는 동봉한 `manifest.json`에 있습니다.

- 부평구청·동대문구: 해당 게시물의 공공누리 제1유형, 출처 표시.
- 대한민국 법원·서울가정법원: 법원 자체 양식의 원본을 출처 표시와 함께 제공합니다. [법원 저작권정책](https://www.scourt.go.kr/portal/popup/jeojak_pop.html)
- 국가법령정보센터·국세청 법정 서식: 법령 별지 서식으로 분류했습니다. [저작권법 제7조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029423769)
- 찾기 쉬운 생활법령정보: 출처를 표시한 법원 등기 양식 원본입니다. [저작권정책](https://easylaw.go.kr/CSP/AboutCopyright.laf?topMenu=introUl3)
- 국세청 작성사례 4개: 국세청이 세목별 신고안내로 공개한 업무상 작성사례로 판단하여 [저작권법 제24조의2](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030281869)에 근거해 출처와 함께 제공합니다. 개별 공공누리 표시 확인 또는 별도 허락 취득을 주장하지 않습니다. 개별 계약·저작권 등록까지 확인한 법률 검토와는 구분됩니다. [국세청 저작권정책](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=6791&cntntsId=8169)

전체가 어느 한 구청의 제공물인 것은 아닙니다. 기관별 출처와 이용 조건을 유지해 주세요.

## 사용 전 확인

자료는 게시 당시 버전이며, 예전 개정일의 양식도 포함됩니다. 최신 법령·관할 기관의 접수 요건과 일치하는지 제출 전에 확인하세요. 기관 예시의 사람과 금액을 실제 고객 자료로 사용하지 마세요.

PDF는 전체 페이지 렌더링과 텍스트를 확인했습니다. HWP v5는 파일 구조·본문을, HWP v3와 Word는 형식·파일 구조를 확인했습니다. 한글·Word 프로그램에서의 전체 인쇄 레이아웃은 미검증입니다. 두 Word 파일은 기관이 `.doc` 확장자로 제공하는 RTF 원본입니다.

웹 사례 변환 PDF는 6쪽 렌더링과 원본 이미지 5장의 내장 픽셀 일치를 검사했습니다. 변환 PDF의 SHA-256은 자체 파일 무결성 검증값이며 기관 제공 PDF와의 해시 일치를 뜻하지 않습니다.

매우 긴 원본 파일명은 저장 경로 길이 제한 때문에 짧게 표시했습니다. 원래 이름은 각 파일의 `originalFilename`에 보존했으며, 문서 바이트는 원본과 같습니다.
