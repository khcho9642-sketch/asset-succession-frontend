# 자산승계360 작성 양식·예시 v1.0

10종 실제 편집파일: DOCX 5개 / XLSX 5개. 각 Excel에는 빈 양식·작성예시·이용안내 시트가 있습니다.
같은 번호의 PDF에서 가상 작성 예시를 확인하세요. 전체 예시는 `00_작성예시_모아보기.pdf`에 묶었습니다.

- `01_편집용_양식`: 실제 작성용 파일
- `02_작성예시_PDF`: 가상 사례를 채운 PDF
- `03_이용안내`: 범위·주의사항·출처
- `04_사이트등록`: 실제 파일 경로와 검토 상태를 담은 JSON

공식 안내를 참고해 새로 작성한 자체 참고 양식입니다. 국세청·법원 원본 신고서식이 아니며 개별 법률·세무 검토는 완료되지 않았습니다. 최종 사용·서명·신고·등기 전 검토가 필요합니다.

차용증 예시 3%는 가상의 약정이율이며, 세무상 적정이자율·면세 보장값이 아닙니다. 개인정보·금융정보는 로컬 파일에서 필요한 범위로만 입력하세요.

사이트 게시 시 실제 파일을 그대로 복사하여 경로를 연결하고, 없는 파일 주소를 만들지 마세요. `publish_status`와 `legal_review_completed`를 임의로 승인 상태로 바꾸지 마세요. 이 작업에서는 GitHub·MCP·사이트를 변경하지 않았습니다.
